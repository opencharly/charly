# 2026.210.1445 — the resolved-project envelope seam-death (#55 step 3-I)

The superproject consumer leg of #55 step 3-I: the **resolved-project envelope
projector** becomes a plugin capability (`build:project`) that its ~8 peer
consumers reach via `InvokeProvider`, and `ResolvedBox` becomes a CUE-sourced
`opencharly/spec` contract. Producer legs already merged: spec `172027b2`
(tag v0.2026210.1533) + sdk `00a21a42` (tag v0.2026210.1407).

## Units (all fold into this one super commit via squash)

- **3a — ResolvedBox → `spec.ResolvedBox` (CUE-sourced).** The build↔deploy
  `ResolvedBox` (the #1 entanglement) is a CUE def in the spec module; `buildkit.
  ResolvedBox` embeds it as a wrapper carrying only the 9 host-render-cache /
  vocab hand fields (the 4 `json:"-"` caches + DistroConfig/DistroDef/
  BuilderConfig/InitSystem/InitDef — the documented gengotypes `json:"-"`
  exception). Core + all 85 plugins consume the merged spec/sdk.

- **3b — resolved-project envelope → `build:project`.** The host-owned
  `resolved-project` HostBuild projector relocates into `candy/plugin-build` as a
  new class-generic `build:project` word (Op `OpResolve`); the **8 consumers**
  (plugin-box inspect, plugin-bundle node-resolve + compile, plugin-check
  check-project, plugin-preempt arbiter, plugin-installstep, plugin-status
  nested-tree, plugin-substrate k8s-status) each swap `HostBuild("resolved-project")`
  → `InvokeProvider("build","project")`. `hostBuildResolvedProject`,
  `buildResolvedProjectFromDir`, `resolvedProjectBuilderKind`, and the
  registration are DELETED from core.

- **3-I — validate-project tolerant → `build:project`.** `build:project` gains an
  `OpValidate` op serving the TOLERANT resolve (reusing loaderkit's built-in
  skip-on-failure contract); the host-natural raw-config checks (CUE-schema /
  build-distro / merge / tunables / remote-candy — needing the CUE library +
  provider registry, a kernel M) stay as the smaller `validate-project-checks`
  leg; plugin-box's `runValidateEngine` calls both + merges. Core's
  `projectResolvedProject` wrapper deleted.

## R1 fix (caught in R10 code review)

`hostBuildOverlay` initially sourced the overlay's `DistroDef` from
`detectHostContext().Distro` (the OPERATOR HOST's distro) instead of the base
image's — a live cross-distro bug (this host is Arch/CachyOS; check-pod-overlay's
base is Fedora, so the overlay would have rendered arch `[aur pac]` formats into
a fedora-base image). `resolveOverlayBaseDistroDef` now does a cheap standalone
resolve of the base box and uses its wire-clean `Distro` tag (mirroring the
deleted `NewGenerator`'s `gen.Boxes[base].Distro`); `detectHostContext()` is the
last-resort fallback only. Regression:
`TestResolveOverlayBaseDistroDef_UsesBaseImageDistroNotHost`.

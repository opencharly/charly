The K1 loader-cone fabric-tail: `charly/resolved_project_host.go` (the trimmed

`fillNamespacedBoxes` host function. The namespaced-box resolve's two deploykit

K3 build-resolve-gated tracked debt).

## What moved / how

- **New CUE wire type `#NamespaceScanReply`** (`spec/schema/buildwire.cue`, the
  `spec` submodule) — a FLAT list of per-namespace scan inputs. The host recurses
  the import-namespace tree ONCE and emits, per namespace: the qualified box
  `child` path, the pre-fix-point `scanned` (`map[string]spec.ScannedCandy`, from
  `projectCandiesScanned` reading `subUF.Candy` in-memory — the R1 fix preserved),
  and the namespace-scoped initial `downloads` (`[]spec.RemoteDownload`, from
  `CollectRemoteRefsOpts` over the namespace's own cfg — the ONE cfg-coupled
  step). The hand-written `spec.ScannedCandy` / `spec.RemoteDownload` types are
  referenced via `@go(,type=…)` overrides (RDD-proven gengotypes spike — no
  duplicate generated types, no `@go(-)`).
- **`hostBuildNamespaced`** (`charly/host_build_buildengine.go`) now returns
  `spec.NamespaceScanReply` (was `spec.ResolvedProject`); the new
  `collectNamespaceScanEntries` recurses `uf.Namespaces` (cycle-guard preserved).
  `initCfg`/`calver`/`dir` come from the plugin's own resolve context and are NOT
  duplicated in the reply; `sub` (namespace `*spec.Config`) is derived plugin-side
  by descending the root `uf.Namespaces` tree by the entry's `child` path
  (`spec.Config` is hand-written with a recursive `Namespaces` map — not cleanly
  serializable, so it stays plugin-derived).
- **`FillNamespacedBoxes` seam** (`candy/plugin-build/resolve_legs.go`) fetches the
  flat reply and folds each entry plugin-side: `loaderkit.ScanCandyFromLocal`
  over the pre-computed `scanned` + `downloads` (the `CollectRemoteRefs` closure
  returns the downloads verbatim; `EnsureRepo`/`ScanRemote` reuse the cfg-agnostic
  shared host legs — `hostEnsureRepoLeg`/`hostScanRemoteLeg`, R3) →
  `deploykit.RawCandyPair` (additive fold into `rp.Candies`/`CandyModels`) →
  `deploykit.FillNamespaceBoxViews` (qualified box views into `rp.Boxes`).
- **`mergeNamespacedInto` DELETED** (obsoleted by the direct fold). The
  `buildengine-namespaced` `typedHostBuilder` registration adjusts to the new
  reply type.

# 2026.216.0557 — the box scaffolder shipped `--candies`; the intent was `--candy`


`charly box new box <name> --base <ref> --candy <a,b,c>` exited 80 with
"unknown flag --candy". The documentation was right and the binary was wrong.

box.go:626 declared:

    Candies []string `long:"candy" sep:"," help:"…"`

The author intended `--candy` — singular, matching the `candy:` YAML key and the
`box add-candy` / `box rm-candy` verbs. But `long:` is go-flags syntax, not
Kong's. Kong ignores it and derives the flag from the FIELD NAME, so `Candies`
became `--candies`. Nothing errors; the intent is simply discarded.
`candy/plugin-check/run_cmd.go` shows the correct form: `name:"agent"`.

The tag is now `name:"candy"`. Verified end to end on a scaffolded project:
`charly box new box --help` shows `--candy=CANDY,...`, and

    charly box new box my-shell --base fedora --candy my-tool

exits 0 and writes box/my-shell/charly.yml composing my-tool — with `candy:` as
the emitted key, so flag and schema now use the same word.

HOW THIS WAS NEARLY MADE PERMANENT. A validator caught the broken command by
RUNNING it, and the first fix changed the documentation to say `--candies`. That
would have cemented an accidental plural — derived from a Go field name — into
the published vocabulary. It was caught by an operator asking why a flag was
plural when everything in charly is singular. The lesson is narrow and worth
keeping: when documentation and code disagree, establish which one holds the
INTENT before deciding which to change. Here the code stated its own intent, in
a tag that had never taken effect.

WIDER FINDING, fixed in the next entry (2026.216.0608): `long:` appeared 326
more times across the tree and Kong ignored all of them. Most were harmless
because the field name already yields the intended flag. The divergence count
is 15, not the ~35 a first static scan reported — that scan modelled Kong's
camelCase split with a naive regex and split initialisms Kong keeps together
(`RunID` is `--run-id`, not `--r-u-n-i-d`). The corrected figure was measured by
asking Kong itself for each field name.

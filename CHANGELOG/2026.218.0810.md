# 2026.218.0810 — the fifth grievance: the tests never travel with the image

`GRIEVANCES.md` grows a fifth grievance: that unit, acceptance and live testing are three
separate systems, and the test/CI system is completely separated from the deployed and
distributed image — the artifact CI tested is not the artifact that ships, and the proof never
travels with the image. The new section names what OpenCharly does instead: the `plan:` of
deterministic `check:` steps is baked into the `ai.opencharly.description` OCI label, and
`charly check box` / `charly check live` / `charly check run <bed>` run that same baked plan
against the built artifact, the live deployment, and a fresh-rebuild disposable bed (the R10
gate). The "four" counts become "five" throughout the document and its closing synthesis.

`candy/plugin-docs/gen_grievances.go` de-counts the site page's description ("Properties of
ordinary container and VM practice…"), so it cannot drift on a future sixth grievance.

`eaba714` while the `docs` gitlink is `4d15846` (introduced when the K-wave 2 gitlink bump

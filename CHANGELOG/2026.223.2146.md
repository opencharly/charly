# 2026.223.2146 — split the Gemini CLI out of google-cloud-npm into the gemini candy

`google-cloud-npm` installed both `firebase-tools` and `@google/gemini-cli` at
unpinned `*` versions. The `gemini` candy already pins `@google/gemini-cli`
(0.51.0) and installs the same binary, so a box composing both candies had its
pinned gemini version silently overwritten by the `*` install.

Surfaced by the parallelized R10 roster. Removed the gemini install + its three
baked checks from `google-cloud-npm` and added `gemini` to its `require:` chain,
so a composing box that also composes `gemini` keeps the pinned version. The
firebase install and checks are unchanged.

# 2026.224.2355 — AgentTeams Unit 7: marketplace family + skills + docs

ships as a first-class `agentteams` marketplace family, discoverable and documented end to end:

- **Marketplace family registry.** `agentteams` joins the `marketplace:` `families:` map
  (category `images`, `profiles: [container]`), so any skill declaring the family is published
  under `plugins/agentteams/` instead of failing the generator's closed family gate.
- **Candy `skill:` entities.** `candy/agentteams/charly.yml` declares the `agentteams` skill —
  the full-stack box (decomposed minio/matrix/element/higress/controller candies, the
  home-relative volumes `~/.agentteams/{minio,matrix,higress,controller}`, container ports, the
  pod and vm deploy substrates, the deploy-overridable `AGENTTEAMS_*` env, and the
  controller-spawns-manager → create-worker → room verification sequence) — and
  `candy/plugin-agentteams/charly.yml` declares the `agentteams-cli` skill — the compiled-in
  `charly agentteams` management CLI (command tree, endpoint/token discovery, declarative
  `apply -f`, worker-create flags).

  `plugins/agentteams/skills/{agentteams,agentteams-cli}` + the `.claude-plugin`/`.codex-plugin`
  manifests and registers the plugin in the marketplace + profiles indexes; `charly docs
  generate` emits the reference pages (10 agentteams candies, the `agentteams` CLI word, the
  plugin-agentteams page) and the `recipes/agentteams/*` pages. Both regenerations are no-ops on
  a clean tree (drift gates green).

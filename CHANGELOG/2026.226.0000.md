capped `/tmp` quota: Go builds and tests must set `GOTMPDIR`/`TMPDIR` to a
root-filesystem scratch dir (e.g. `/home/atrawog/.cache/go-tmp`) so the sandbox

missing-`TMPDIR` false positive, not a real lint failure. The

# 2026.226.2134 — add the deepseek-harness (dsh) candy + plugin-dsh management plugin; raise the nodejs floor to Node 22

Two new entities plus a nodejs floor bump, verified end-to-end on the
`check-dsh-pod` and `check-docs` R10 beds.

## The dsh candy (`candy/dsh/`)

Installs the deepseek-harness `dsh` CLI (npm package `@deepseek-ai/dsh`
0.1.0-rc.6, pinned) into a box via the npm builder, and runs the `dsh web`
Web UI as a supervised service. The web app binds **127.0.0.1:3080 only** —
dsh-web-app 0.1.0-rc.6 hard-rejects `--host 0.0.0.0` (RCE safety) — so the
charly-owned `dsh-entrypoint` runs `dsh web` in the background and exec's a
socat forwarder on `0.0.0.0:3081` that forwards to loopback. socat cannot
share port 3080 (Linux forbids a wildcard + specific listener pair on one
port — verified empirically in the pod), so the published port maps the
auto-allocated host port to container 3081; `${HOST_PORT:3081}` resolves it
in checks. The `~/.dsh` volume persists profiles + plugin data.

## The plugin-dsh management plugin (`candy/plugin-dsh/`)

A compiled-in `command:dsh` + `verb:dsh` plugin (the agentteams pattern).
`charly dsh status --box <name>` / `profile list` / `plugin list` reach a
deployed box over the pod-lifecycle reverse channel (plugin-cmd pattern);
the `dsh:` check verb (`version` / `web-running` / `profile-list` /
`plugin-list`) probes **in-box** via `cc.Exec().RunCapture` — the one place
plugin-dsh diverges from plugin-agentteams' host-based `cc.ResolveEndpoint`
(the loopback-bound web UI is probed on 127.0.0.1:3080 inside the venue).

## The nodejs floor bump (Node 22 LTS)

The `nodejs` candy's Ubuntu + Debian sections now install NodeSource
**node 22.x** (was 20.x) — the deepseek-harness dsh floor (`^22.19.0 ||
>=24.0.0`). Debian drops the separate apt `npm` (NodeSource bundles npm;
the apt package pulls conflicting node-* deps — the rationale Ubuntu
already documented). Fedora/Arch unchanged (distro nodejs 22/24 already
satisfy dsh). A real exit-status check asserts node `>= 22.19.0` (no
`${...}` in the command — charly's variable substitution would silently
skip the step).

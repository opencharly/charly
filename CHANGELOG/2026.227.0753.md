  The claim-keyed sweep (R1) traced it to its ORIGIN: `CHANGELOG/2026.225.2248.md`
  — the unit 2 entry — carries the same typo four times, and that is where the
  north-star draft inherited it. Confirmed a typo and not a rename: `helm_chars`

  history returns nothing), the schema field is and always was
  `spec/schema/deploy.cue`'s `helm_charts?: [...#HelmChart]`, and line 9 of that
  same CHANGELOG spells it correctly.

  **That historical entry is deliberately left as-is.** A first pass corrected all
  four occurrences in place; that was wrong and is reverted. A merged
  `CHANGELOG/<CalVer>.md` is immutable, exactly like the tag sharing its CalVer
  (`v2026.225.2248`) — closed history that follow-up work never edits, "even to
  add a directly-related narrative." The over-reach came from applying R1's
  claim-keyed sweep to the one surface R5 explicitly exempts: its grep self-test
  is satisfied when an old identifier "returns only `CHANGELOG/` history."

  So the sweep's correct endpoint is here, in the live entry, not there. Post-fix,
  `helm_chars` survives in exactly two places, both sanctioned: the merged unit 2
  changelog (R5's permitted `CHANGELOG/` history) and this entry's own narrative
  naming the wrong identifier in order to correct it — the same allowance R5
  grants migration help-text. Stated with its unit, since a line-counting and an
  occurrence-counting grep disagree here: 4 occurrences across 3 lines in the
  merged entry, 4 across 4 lines in this one — so `git grep -c` reports 7 and
  `grep -o | wc -l` reports 8. Zero USES anywhere: `plugins`, `spec`, `sdk`, and
  `docs` return nothing, and no live superproject surface spells the field that
  way.
- **The kubeconfig claim was imprecise** — stated as a fixed path, it is a
  precedence chain. Corrected twice: the first correction named only two arms
  while calling itself a precedence chain, which round 3 caught. It has THREE

  code does not have is worse than silence: a reader hardens nothing because
  they believe it is already hardened. Restated as the REQUIREMENT it is, with
  the default named; unit 7 absorbs the listener alongside the
  `--disposable-only` filter (both are the same license), and a matching

## Consumer migration (R3 duplication / R5 legacy / SDD)

- **StepContract → typed form**: the plugin call sites migrated from the deleted
  string form to the typed `spec.StepContract` constants (`spec.ScopeSystem`,
  `spec.VenueHostNative`, `spec.GateNone`, …).
- **LocalPkg**: the deploy-plan consumers migrated onto `Packaging()`
  (the candy-body `localpkg:` removal itself landed in the nFPM cutover's
  `remove-candy-localpkg` migration).
- **install_template → phases**: the legacy top-level `install_template` field is
  removed; the embedded build vocabulary migrates into
  `format.<fmt>.phase.install.container` / the builder equivalent, driven by the
  new `install-template-to-phases` Go reshaper migration
  (`candy/plugin-migrate/reshape_install_template_to_phases.go`).
- **DeployTarget → EmitTarget**: the renamed IR-emission contract; every charly
  reference swept (R5) — `git grep DeployTarget` now returns only `CHANGELOG/`.
- **CUE-sourced wire types**: `GpuSwitch*`, `MCPProvideEntry`, the ledger records,
  `EnvProvideEntry`/`ProvidesConfig`, and the check-context
  `CheckHTTP*`/`CheckVerbResult`/`CheckGraphicsEndpoint` wire shapes are now
  generated from CUE defs; the hand-written duplicates deleted (consumers
  repointed).
- **spec/spec slicing**: the `calver` extraction — `spec.ParsedCalVer` /
  `spec.ParseCalVer` / `spec.LatestSchemaCalVer()` now live at
  `calver.ParsedCalVer` / `calver.ParseCalVer` / `calver.LatestSchemaCalVer()`;
  consumers repointed.
- **Naming**: acronym casing (`SshKey` → `SSHKey`, `VmSSH` → `VmSsh`) and version

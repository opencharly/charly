# 2026.232.1450 — pi integration: system prompt injection, skill loading tool, worktree tools, prompt templates, sub-agent instructions, PR body validation

Implements the pi integration plan (`PROGRAM/pi-integration.md`):

- **Layer 1 – System prompt injection:** `charly-gates.ts` now injects condensed
  R0–R10 rules, PR body requirements, and attribution tiers into the system
  prompt every turn via `before_agent_start`. Survives compaction.
- **Layer 2 – Skill loading tool:** `charly_load_skills` custom tool that reads
  the AGENTS.md dispatcher table and loads matching SKILL.md files.
- **Layer 3 – Prompt templates:** `.pi/prompts/` with `/cutover`, `/pr-body`,
  `/skill`, `/rulebook`, `/subagent-review`, `/subagent-verify`.
- **Layer 5 – Sub-agent instructions:** AGENTS.md updated with pi-specific
  `subagent` tool usage, `skill:` parameter, `workflowScript` parallel fan-out,
  and async background beds. `.pi/subagents/charly-agents.json` with reviewer,
  worker, and validator agent definitions.
- **Layer 6 – PR body validation:** `pre-push-gate.sh` now checks open PRs for
  required sections (`## Summary`, `## How tested`, `## Project-rulebook
  rule-compliance`, `## Change Classification`, `*Assisted-by:*` footer).
- **Layer 7 – Worktree tools:** `charly_worktree_create` and
  `charly_worktree_remove` custom tools for worktree lifecycle management.

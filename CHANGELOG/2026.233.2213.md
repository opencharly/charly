## chore: ignore .pem private keys

GitHub App and bot private keys (e.g. `charly-auto-merge.*.pem`) are
downloaded into the checkout root during operator setup. `*.pem` is now
ignored so a key can never be committed accidentally.

### How tested

`git check-ignore` against a `.pem` file in the checkout root:

```
$ touch test-key.pem && git check-ignore -v test-key.pem
.gitignore:XX:*.pem  test-key.pem
```

(The ignore rule matches; the actual key file was kept outside the repo.)

### Change class

Documentation/config — `.gitignore` only. Non-runtime standards.

# 2026.234.0347 — Sweep-based tag-on-merge dispatcher

`pull_request: closed` never fires for auto-merges (the merge event
action is `merged`, an invalid trigger type), so the closed-based
dispatcher never tagged. The dispatcher now runs the org-wide sweep
(`workflow_run` on the validator + a 15-minute schedule) which tags
every merged PR lacking its CalVer tag.

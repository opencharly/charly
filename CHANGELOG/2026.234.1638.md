# 2026.234.1638 — docs: PR body IS the changelog — tag-on-merge lands CalVer at merge

## Summary

Updates the candy source entities (`candy/charly-internals/charly.yml`) for the redesigned org landing flow: **the PR body IS the changelog**.

### What changed and why

- **OLD:** authors staged a placeholder `CHANGELOG/<CalVer>.md` in every PR diff; the pr-validator renamed it at merge via bot-token Contents-API pushes — a cyclic loop that left stale red checks.
- **NEW:** `charly/pr-validator` AI-review → PASS → GitHub native auto-merge (squash). After merge, the org-wide `tag-on-merge` workflow writes `CHANGELOG/<CalVer>.md` from the merged PR title + body and mints the `v<CalVer>` tag.

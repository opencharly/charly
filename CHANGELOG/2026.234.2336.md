# 2026.234.2336 — feat(charly)!: resolve the sdk contract module from the module proxy (drop the sdk submodule)

## Summary

The `sdk/` git submodule is removed from this repository — no gitlink, no `.gitmodules` entry, no local checkout. Every module that needs it (the 94 candy modules + the two `tools/golden-*` fixture modules) now requires `github.com/opencharly/sdk` at the single shared pin **v0.2026234.347** (the sdk tag on the exact commit the submodule pinned, `e7c3440`) and resolves it from the module proxy — the require version IS the resolution, exactly like the spec contract module since charly#371. The 95 `replace github.com/opencharly/sdk => ../../sdk` directives are deleted.

**Deleted surface**: `.gitmodules` sdk entry + gitlink; `use ./sdk` in `go.work` (regenerated by pluginsgen) + pluginsgen's sdk bootstrap guard; the `check-local-vm` bed's guest-delivery `rsync -a ./sdk/` step; the gomod-canonical replace assertions (Shape-A' asserts the shared pin + the ABSENCE of contract replaces; `TestSpecPinsMatchSDK` → `TestContractPinsMatchShared`); `task mods:tidy`'s replace-based membership (now require-based); every sdk-submodule claim in `charly.yml`, `check/eval-host-project/charly.yml`, `candy/charly-internals`, `candy/charly-build`, `plugin_build_stamp.go/.test`, `plugin_loader.go`, `ci.yml`, `.golangci.yml`, and the regenerated `AGENTS.md`/`CLAUDE.md` dispatcher. The build-stamp mechanism is unchanged (generic local-replace content hashing stays for vendored replaces like plugin-spice); the synthetic test fixture no longer borrows the real org module names.

**Cross-repo sequence**: the plugins corpus leg (opencharly/plugins#224) + the docs leg regenerate the skill/reference pages; the umbrella leg (opencharly/opencharly#10) drops sdk from `CHARLY_PINNED`; this PR bumps the plugins/docs gitlinks after those legs merge (landing-sequence step, not a follow-up).

# 2026.235.0001 — sdk de-submodule: the contract module resolves from the module proxy
<!-- auto-merge-finalized: 2026.235.0001 -->

The `sdk/` git submodule is removed from this repository — no gitlink, no
`.gitmodules` entry, no local checkout. Every module that needs it (the 94
candy modules + the two `tools/golden-*` fixture modules) requires
`github.com/opencharly/sdk` at the single pinned version **v0.2026234.347** —
the sdk tag on the exact commit the submodule previously pinned (`e7c3440`) —
and resolves it from the module proxy. The local
`replace github.com/opencharly/sdk => ../../sdk` directives (95 files) are
deleted: the require version IS the resolution. A fresh non-recursive clone
needs no sdk checkout of any kind; `git submodule update --init plugins docs`
plus the proxy is sufficient to build.

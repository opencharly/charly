# 2026.235.1106 — feat(marketplace): de-submodule plugins — standalone marketplace + native harness loading

## Summary

The **marketplace de-submodule cutover**: `plugins` is removed as a charly submodule; the corpus now lives in the standalone **opencharly/marketplace** repo (renamed from plugins), which pins charly in its own `.gitmodules` and regenerates the corpus under a drift gate in its own `deploy.yml` — the docs-repo pattern. Every harness loads the corpus natively from the marketplace repo — **zero local-path plugin loading remains in charly**.

**Generator split** (`candy/plugin-marketplace`): `generate`/`drift` gain a required `--out` (the marketplace checkout). Corpus emissions (the legacy `plugins/` prefix stripped) go there; the charly-local harness surface (`.claude/hooks` + `settings.json` merge, the R0 dispatcher in `CLAUDE.md`/`AGENTS.md`) stays under `--root`. New emissions: `.agents/plugins/marketplace.json` (Codex/AGENTS catalog — previously hand-authored in charly), `kimi.plugin.json` (the whole marketplace is one kimi plugin), `package.json` (the whole marketplace is one pi package). Per-family manifests **drop the `version` field** (commit-SHA versioning per the Claude Code marketplace docs); repository metadata points at `opencharly/marketplace`; `.claude/settings.json` registers the marketplace by its **github source** instead of a local directory.

- **plugin-docs** gains `--plugins <dir>` (the marketplace checkout the skill corpus is read from; default `<root>/plugins`) — the docs deploy passes its marketplace submodule.
- `git rm plugins` + `.gitmodules`; `scripts/drift-baseline.sh` deleted (its only consumer is gone — the skills gate is strict; the corpus gate lives in the marketplace CI).
- `taskfiles/Skills.yml`: `skills:sync`/`skills:drift` regenerate the charly surface + the marketplace checkout (`MARKETPLACE_DIR`); new `marketplace:pin` (MARKETPLACE_REF vs the marketplace repo's live main HEAD — mirrors `docs:pin`).
- **Harness rewires**: `.agents/` (the ~140-skill symlink farm + `.charly-profile.json` + the hand-authored catalog) **deleted** — pi consumes the marketplace as a pi package, Claude Code via the marketplace, kimi as a plugin; `.reasonix` + kimi hook guards no longer probe a `plugins/` dir; `.pi/settings.json` gains the marketplace git package; AGENTS.md/CLAUDE.md/README.md + the family candy descriptions + the internals skills teach the standalone marketplace.
- **check-marketplace bed** (`candy/plugin-marketplace`): clones the published marketplace at the immutable `MARKETPLACE_REF` and gates its shape (catalogs parse, `INSTALLED_BY_DEFAULT`, no version fields, baked skill headers, executable setup, pinned-commit check).

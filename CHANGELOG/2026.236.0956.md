# 2026.236.0956 — feat(candy/charly): install charly from the published per-distro package repos

## Summary

The charly meta-candy's plan baked the binary via `copy: bin/charly` — the in-repo artifact at `candy/charly/bin/charly`, synced by `task build:binary`. When a box repo resolves the candy from the **published** charly repo at a pinned tag, that artifact does not exist, so the compose fails at `COPY --from=charly bin/charly` (the pre-existing failure blocking the batch-1 box PRs' R10).

This change installs `charly` from the published per-distro package repos (`charly-{debian,ubuntu,fedora,arch,alpine}` on GitHub Pages) via the declarative `distro:` + `package:` + `repo:` mechanism, and removes the baked `copy: bin/charly` step (R5 hard cutover, same change):

- **debian/ubuntu**: apt repo (suite `stable`, component `main`, `charly.gpg` key)
- **fedora**: dnf baseurl form (`repo/amd64` + `RPM-GPG-KEY-charly` gpgkey)
- **arch**: pacman `server` + **pinned signing key** `978DFF11A951A830F7ADA2D4062B073E9D1BAE2E` (published to keyserver.ubuntu.com) with `siglevel: Required DatabaseOptional` — signature-verified like every other distro entry (the initial `Optional TrustAll` was replaced after the validator's supply-chain finding)
- **alpine**: apk repo (amd64 dir with APKINDEX + `charly.rsa.pub` key)

**Dependency bump (go.mod/go.sum)**: `github.com/opencharly/sdk` v0.2026235.1716 → **v0.2026236.813** (sdk#162, merged). The repo install requires sdk#162's `CompileLocalPkgStep` skip (when the candy's `distro:` repo provides the packaged name, the localpkg fallback must not fire) — without it a box composing the charly candy double-installs charly and apt fails with `Packages were downgraded and -y was used without --allow-downgrades`. The go.sum diff also carries the transitive hash updates for that version (fsnotify/renameio additions, go-spew/go-difflib removals, go-isatty bump).

**Regression test**: `TestDistroRepoInstallDeclared` (charly/packaging_test.go) asserts the candy's `distro:` section declares the charly package + a repo entry for every published distro. **Fails on origin/main** (debian/ubuntu carry only `tailscale`; fedora/arch/alpine have no distro entry — all five errors above), passes with this change.

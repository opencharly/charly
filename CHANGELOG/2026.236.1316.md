# 2026.236.1316 — fix(candy/charly): correct the fedora repo URL (amd64/, not repo/amd64/)

## Summary

The charly candy's fedora `repo:` entry (landed in charly#388) pinned `https://opencharly.github.io/charly-fedora/repo/amd64/` — but the published charly-fedora repo serves its dnf repodata at **`https://opencharly.github.io/charly-fedora/amd64/repodata/repomd.xml`** (HTTP 200). The `repo/amd64/` path 404s, so a fedora box composing the charly candy fails at `dnf install charly` with **`No match for argument: charly`** (the repo isn't readable).

This change corrects the URL to `https://opencharly.github.io/charly-fedora/amd64/` (verified live: repomd.xml 200).

The corrected URL is verified by the live curl 404→200 repomd.xml checks above; the full post-fix compose completes only after charly#385 lands and the box advances its charly ref.

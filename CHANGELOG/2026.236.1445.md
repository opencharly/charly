# 2026.236.1445 — rebrand to the Open Infrastructure Compiler

The product's positioning changes from "The fully equipped factory floor for
you and your agents" (and the "Agent-in-the-Loop Factory" name it succeeded)
to **"The open infrastructure compiler — for you and your agents."** The
README states the intent directly: charly brings the idea behind LLVM — one
intermediate representation, many backends — to infrastructure deployment,
driven by agents as readily as by people. The candy/box vocabulary is
untouched: `candy:` and `box` are schema keywords, not branding.

## README.md — rewritten, claim-audited, cold-read

`README.md` is rewritten end to end, not just retitled:

- **Reading order**: what-it-is → Install → the smallest real example
  (tutorial-shell, the four stages, the substrate swap) → How it works →
  Vocabulary (the glossary, moved to reference position) → Agents →
  Documentation.
- **Every factual claim audited against the live tree.** Fixed in this
  cutover: the stale example pins (`v2026.201.0706` → `v2026.231.0714`); the
  claim that `check-tutorial-shell` carries a `plan:` (it deliberately does
  not); the `spec/schema/node.cue` path (the schema lives in the
  `github.com/opencharly/spec` module — the README no longer cites internals);
  quadlet naming (`charly-<name>.container`, realised as
  `charly-<name>.service`); "no `nested:` field" scoped to the authored
  surface; `opencharly/plugins` → `opencharly/marketplace` (renamed repo); the
  harness list (Claude Code, Cursor, Codex CLI, Kimi Code, pi) and the removed
  developer/user/container install modes; all five substrates out-of-process
  (not three); Go-type generation relocated to the spec repo; unverifiable
  citations (test file names, verbatim error strings) dropped rather than
  asserted.
- **Twelve cold-reader review rounds** (~120 findings fixed): clarity,
  duplication, needless-sentence, and readability standards, applied by fresh
  context-free reviewer agents until the finding rate bottomed out.

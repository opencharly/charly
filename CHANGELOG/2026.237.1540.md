## Summary

The candy de-submodule cutover, Phase 2c: **92 plugin candies advance to their standalone module paths** — every `plugin.source:` field, go.mod module path, and Go self-import becomes `github.com/opencharly/plugin-<name>/candy/<name>` (the standalone repo module path, matching the plugin-generate-packages precedent). The companion umbrella PR (opencharly/opencharly#26, MERGED) adds the 92 repos as submodules.

The charly module's go.mod now requires the standalone plugin module paths (57 stale in-repo requires dropped by `go mod tidy`).

**go.work decision:** kept `use ./candy/<name>` (regenerated by pluginsgen on every build) — the in-repo candy dirs stay as workspace members at the new module paths until Phase 4 deletes them; the sibling/proxy rework is Phase 4's job.

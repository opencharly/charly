# 2026.240.2158 — chore(refs): bump pod-charly-hooks to v2026.240.2141 (removes the internals stdio github MCP server)

## Summary

Bumps the `pod-charly-hooks` candy ref from `v2026.239.1634` to `v2026.240.2141`,
picking up opencharly/pod-charly-hooks#2.

That PR removed the `internals` plugin's stdio `github` MCP server:

```yaml
mcp_servers:
  - name: github
    type: stdio
    command: "github-mcp-server"
```

`charly-internals` ships no pod — it is contributor tooling — and the candy
neither installs nor declares `github-mcp-server`, so on any host without that
binary the server failed to start on **every** session. It also duplicated the
`gh` CLI that `/charly-internals:git-workflow` already mandates for the same
operations. The other four `mcp_servers` blocks in that candy are `type: http`
endpoints served by the pod each plugin ships; those are correct by construction
and are untouched.

This is the propagation step: the source fix landed in the candy repo, and this
pin is what carries it into the generated corpus.

- **R1 — RCA every anomaly.** The removed server was root-caused (undeclared
  host binary; no pod to serve it) before any change, and the four legitimate
  pod-provided servers were explicitly distinguished rather than swept up with it.
- **R3 — No duplication.** The declaration duplicated the `gh` CLI path; one
  canonical route for GitHub operations remains.
- **R4 — No workarounds.** The pin is bumped to a real merged tag; no hand-edit
  of the generated corpus, and no local install of `github-mcp-server` to prop
  up an undeclared dependency.
- **R5 — Delete legacy completely.** The block, the `mcpServers` manifest key,
  the `.mcp.json` artifact, and the description clause all go together.
- **R6 — Git safety.** `gh pr list` preflight across every affected repo;
  `chore/` branch, no force-push, no hook bypass, no direct push to `main`.
- **R7 / R10 — Prove the gate, not the plan.** `task skills:drift` pasted above,
  run on the final committed tree, with the artifact-count delta as an
  independent cross-check of the intended deletion.
- **Pin discipline.** `v2026.240.2141` is a merged, tagged ref on

  stdio github MCP server (#2)"), never a PR branch.

# 2026.240.2219 — fix(build): a plugin candy that fails to compile is a fatal error, not a warning

## Summary

A plugin candy that fails to COMPILE was reported as a `warning:` and the build continued, then died later on `no provider registered` — an error naming the wrong cause. The actionable error (the plugin name + the go build error) was buried above it.

`hostBuildConnectPlugins` (`charly/host_build_buildengine.go`) now returns the error instead of emitting a warning, so the build stops immediately with the actionable message. The plugin-side caller (`candy/plugin-build/resolve.go`, companion PR in opencharly/plugin-build) propagates it.

Fixes opencharly/charly#326.

# 2026.241.0741 — fix(skills): repair the two marketplace-generation gates

## Summary of changes

Both gates guarding marketplace-corpus generation are broken on `main`, and one of them takes
the whole local generation path down with it. Neither can pass on a fresh clone today.

- **`task skills:refs` fails**, and `skills:sync` + `skills:drift` both declare `- task: refs`
  as a dep — so **no contributor can regenerate or drift-check the corpus at all**. It is a
  byte-exact `diff -q` of `candy/charly-marketplace/charly.yml` against the marketplace's copy,
  and charly#432 / marketplace#237 landed the SAME fix with DIFFERENT comment wording. Every
  version pin in the two files already agrees; a 5-line comment block is the entire delta.
  Fixed by adopting the marketplace's wording, which the gate itself calls AUTHORITATIVE ("its
  deploy workflow copies it over this repo's before generating"). No pin entry is touched —
  the diff is comment prose only.

- **`task skills:pin` fails**, always, on a path that no longer exists. It reads
  `candy/plugin-marketplace/charly.yml`, deleted by the Phase-4 de-submodule cutover that moved
  that candy to the standalone `opencharly/plugin-marketplace` repo. `grep` on a missing file
  yields an empty `MARKETPLACE_REF`, which the task then reports as "drift" against the live
  marketplace head, telling the reader to "bump both occurrences in
  candy/plugin-marketplace/charly.yml" — a file that is not there. A gate that cannot pass
  truthfully is worse than no gate.

  `MARKETPLACE_REF` genuinely lives in that other repo now, so charly cannot assert it without
  reaching across a repo boundary. What charly still OWNS is the candy ref it pins in
  `charly.yml:3317` — and because the pinned candy carries the `MARKETPLACE_REF` the
  `check-marketplace` bed clones, a stale ref pins a stale marketplace commit transitively.
  The gate now asserts that: the pinned `plugin-marketplace` ref versus that repo's latest
  published tag. Same anti-staleness purpose, expressed through the lever that still exists.

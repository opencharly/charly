# 2026.241.0848 — fix(skills): correct charly's own candy skills to the current schema and CLI

## Summary of changes

Seven skills that charly's own candies own document shapes, keys, defaults or commands the
schema and binary reject. One of them makes **every example in the skill** unloadable.

Concrete edits, all inside `skill:` entity bodies:

1. **`charly-check:wl-overlay` — every example is in a rejected shape (the blocking defect).**
   All 12 examples were name-keyed maps (`title-card: {run: …, wl: overlay-show, type: …}`) with
   the verb's fields as step SIBLINGS. `plan?: [...#Step]` is a LIST, and `#Op` is CLOSED, so the
   loader refuses the file outright: `plan must be a step LIST (got yaml kind 4)`. Rewritten to
   ordered list items with the verb fields inside the `wl:` map beside `method:` — exactly the
   form the sibling `/charly-check:wl` skill already documents, so this also removes a
   contradiction inside one candy. The two prose claims that taught the sibling-field rule are
   rewritten too.
2. **`charly-build:settings` — two inverted env vars and three wrong defaults.** The table gave
   `CHARLY_ENGINE_BUILD` / `CHARLY_ENGINE_RUN`; the real names are `CHARLY_BUILD_ENGINE` /
   `CHARLY_RUN_ENGINE` (`plugin-settings/config.go:555-558`), and all three defaults are `auto`,
   not `docker`/`quadlet`. An agent exporting the documented names changes nothing.
3. **`charly-build:generate` — denies a supported invocation.** It stated `charly box generate`
   "takes **no positional image argument**". It takes an optional box list; the positional is
   accepted.
4. **`charly-kubernetes:kubernetes` — the flagship `probes:` example does not validate.**
   `#DeployProbes` types each probe as a bare closed `#Op`, so there is no `http:` sugar inside
   `probes:` (the plugin-verb desugar runs on plan STEPS only). Rewritten to the op form, with a
   comment saying why.
5. **`charly-image:layer` — a removed field and four Go names as YAML keys.** The candy-level
   `libvirt:` raw-XML-snippet row is deleted (the field was removed — `spec/schema/candy.cue`),
   and the supervisord lifecycle fields are corrected to the SINGULAR YAML keys `start_retry` /
   `start_sec` / `exit_code` / `event` (the Go names are plural — the same trap as `ssh_arg`).
   `exclude_distros:` → `exclude_distro:`.
6. **`charly-image:image` — `extract:` is not a box field.** It sat in the image field table;
   authoring it on a node carrying `base:` fails closed with `extract: field not allowed`, while
   the same key on a layer validates. Replaced with an explicit callout pointing at the layer.
7. **`charly-check:libvirt` — a wrong CUE def and a nonexistent command.** `#LibvirtInput` is a
   DIFFERENT type (the VM domain schema); the verb's input def is `#LibvirtVerbInput`. And the
   skill routed operators to `charly check libvirt guest file …`, which exits 80 — its own
   sibling reference already said no such host subcommand can exist.

# 2026.241.1031 — feat(git): route every host git operation through the centralized GitClient; cache in the per-host charly.yml

## Summary

The per-host charly.yml (`~/.config/charly/charly.yml`) is the SINGLE home for local system state — deployments (`deploy:`), install records (`ledger:`), local system info (`system:`), and cache status (`cache:`). The git metadata cache the loader resolves @github refs with lives in its `cache:` section (spec#66), NOT in ad-hoc JSON files under `~/.cache/charly/repos`.

- **`charly/git_client.go`** (new): the charly-core process-wide GitClient singleton (`spec/refs.GitClient`); the host seams share it instead of calling the raw git primitives directly (R3).
- **`host_build_remote_image_resolve.go`**: `refs.GitLatestTag` → `gitClient().LatestTag` (cached, 24h TTL).
- **`host_build_box_fetch_resolve.go`**: `refs.GitDefaultBranch` → `gitClient().DefaultBranch` (cached, 24h TTL).
- **`plugin_prescan.go`**: `builtinOnlyInvocation()` skips the remote prescan fetch for version/help/settings/ssh — the 13s `charly version` hang (issue #423).
- **`host_build_retention_defaults.go`** (new): the retention-defaults seam reads charly.yml defaults directly (no walk, no refs) — the #423 clean-hang fix.
- **`charly.yml`**: schema migration 2026.232.0520 → 2026.240.1943 (required by the new spec).
- **`go.mod`**: spec v0.2026241.931 (cache-in-charly.yml), sdk v0.2026241.933 (git-layer wiring), plugin-vm v0.2026240.2034, plugin-check v0.2026241.920 (dev-worktree allowance).
- **Box submodules**: advanced to the schema-2026.240.1943 migrations (arch/cachyos/debian/fedora/ubuntu).
- **Test fixtures**: migrated to schema 2026.240.1943; the cargo-builder test expects the new `/tmp/charly-cargo-src` rendering (sdk PR #180); the kernel manifest + host-builder whitelist document the new files.

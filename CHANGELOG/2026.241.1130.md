# 2026.241.1130 — refactor: charly stops generating the marketplace

## Summary of changes

Phase B.6 of the approved cutover: **charly stops generating the marketplace.**

`plugin-marketplace#6` (merged) removed the generator's second job — writing charly's
`.claude/hooks`, merging `.claude/settings.json`, splicing the R0 dispatcher. With that gone the
generator emits only the corpus, which the marketplace repo's own workflow already produces. So
charly has nothing left to generate, and `taskfiles/Skills.yml` has no job.

Concrete edits:

- **`taskfiles/Skills.yml` deleted** (−148 lines): `sync`, `drift`, `refs`, `pin`.
  - `refs` was the byte-equality gate between charly's mirror of the refs list and the
    marketplace's authoritative copy. It exists only to keep **local** generation faithful to CI —
    and there is no local generation any more.
  - `pin` was added earlier in this session to police a pin this cutover removes.
- **`Taskfile.yml`** — the `skills:` include removed.
- **`charly.yml`** — two prose blocks the change makes stale, both describing the
  `check-marketplace` bed: each cited `task skills:drift` as its coverage, and each asserted "the
  setup launcher ships executable". The setup launcher is no longer emitted at all.

- **`candy/charly-marketplace/` deleted** (−189 lines) — charly's mirror of the refs list. This PR
  kills its last reader, so it does not survive as a legacy path. It is provably dead: CI does
  `mkdir -p /tmp/charly/candy/charly-marketplace` and copies the marketplace's **authoritative**
  copy over it before generating, so charly's is overwritten sight-unseen; local generation was
  its only other reader and goes with `Skills.yml`; and a repo-wide grep finds no other reference.

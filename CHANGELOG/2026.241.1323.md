# 2026.241.1323 — fix: build the 9 welded plugins from their own repos, at pins

## Summary of changes

The release workflow builds each welded command plugin with `cd candy/$p`. **Every one of those
directories moved to its own repo** in the candy de-submodule cutover, so that `cd` cannot succeed:
the release pipeline is broken, and has been since its last successful run on **day 234** — the
cutover landed after it.

This was filed as Phase F.3, "a dead reference to sweep". It is not a dead reference. It is a
broken release.

### The fix

`scripts/host-command-plugins.txt` already declares itself the **single source (R3)** for the
welded plugin set. It is given what it needs to actually be one — a pin per plugin:

```
plugin-doctor@v2026.239.1615
```

The workflow clones `opencharly/<name>` at `<tag>` and builds `candy/<name>` from that checkout.

**Why the pin lives here and not in `charly/go.mod`:** go.mod carries only **7 of the 9**. The two
command-only plugins (`plugin-secrets`, `plugin-udev`) are not compiled in, so they have no require
line. A pin source that covers 7/9 is not a source.

The arm64 leg now **reuses the checkout the amd64 leg cloned**, so both arches build the *same
commit* instead of resolving the ref twice.

`readWeldedPlugins` parses `<name>@<tag>` and **rejects a bare name** rather than tolerating it. A
bare name is malformed, not a legacy form — the workflow rejects it too, so accepting it in the test
would let the gate pass on a list the release cannot build.

## Change class

**CI + build tooling** — one workflow, one pin list, one test parser. No charly runtime source, no
schema edit, no candy manifests.

**Closes / relates to:** Phase F.3; follows `opencharly/charly#452`. The remaining `candy/charly`
coupling in the same workflow (the `packaging:` staging step) belongs to the meta-candy extraction
and is deliberately **not** touched here.

**Breaking change + rollback:** `host-command-plugins.txt` changes format from `<name>` to
`<name>@<tag>`. Both consumers move with it in this commit, and the test now fails loudly on the old
format rather than silently accepting it. Rollback is a plain revert.

# 2026.241.1535 — chore(pin): advance the distro submodule + import pins to the fixed distro tags

## Summary

Fixes the 564 `remote candy name conflict` errors in `charly box validate` (opencharly/charly#437). Root cause (RCA): the charly repo's five `box/*` submodule gitlinks and its `import:` pins pointed at **pre-cutover distro tags** that still carried `@github.com/opencharly/charly/candy/<name>` refs. Those refs resolve an old charly tag (e.g. v2026.240.0759) that still ships `candy/<name>` — so every candy provided by a standalone repo (waybar, valkey, rust, hermes, charly, charly-mcp, …) ALSO appeared as provided by `github.com/opencharly/charly`.

The distro repos themselves were already fixed upstream (distro-arch#31, distro-cachyos#34, distro-debian#21, distro-fedora#44, distro-ubuntu#21). This PR is the **pin sync**: point the charly repo at the fixed tags.

# 2026.242.0511 — fix(provider): fail fast on a hung plugin call — apply a default invoke timeout

## Summary

Fixes the fleet-del VM-member hang (the recurring deadlock): a host→plugin call with no caller deadline deadlocked forever — the `charly fleet del` for a VM member + its out-of-process plugins sat in futex_wait for hours (0% CPU). `invokeTyped` (the ONE host→plugin call codec, R3) now applies a default 10-minute timeout when the caller did not provide a deadline, so a hung plugin fails fast with a clear `context deadline exceeded` error instead of deadlocking the host.

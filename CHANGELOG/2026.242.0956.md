# 2026.242.0956 — fix(pi): overhaul the charly pi agent config

## Summary

Fix the charly repo's per-repo pi agent config (RCA'd 2026-08-30, same root cause as the umbrella's):

1. **Dead agent config → working agents.** `.pi/subagents/charly-agents.json` was never read by pi-subagents (agents are markdown files or `subagents.agentOverrides`; the JSON format is dead). The custom reviewer/worker/validator agents were therefore never loaded. Root-caused the tool-less child issue: the `--tools` allowlist path drops the core builtin tools (read/grep/find/ls/edit/write) in children, while `tools: "inherit"` gives a builtin the full default surface. Fix: `subagents.agentOverrides` for reviewer/worker with `tools: "inherit"` + a `validator` markdown agent at `.pi/agents/validator.md`.
2. **System prompt strengthened.** The injected rules block now mandates: skills are living documents (updated in the SAME change, R1), ALL issues fixed (pre-existing or not, R2), use subagents/fabric whenever possible (R2a).
3. **Stale README row removed.** `.pi/README.md` listed `pi-lens` 4.0.1 as a project package, but it was removed from settings.json in fa07b136 — the table row is deleted.

# 2026.242.1139 — chore(deps): bump plugin-check to v0.2026242.1018 for the two bed-diagnostic allowlist fixes

## Summary

Bumps charly's compiled-in `plugin-check` from `v0.2026241.920` to **`v0.2026242.1018`**,
picking up two bed-diagnostic allowlist fixes that both landed in `plugin-check` and that
charly is behind.

**1 — the `--needed` allowance did not match epoch versions.** pacman renders an epoch as
`<name>-<epoch>:<ver>-<rel>`:

```
warning: rust-1:1.98.0-1.1 is up to date -- skipping
```

The existing rule's version pattern had no `:`, so every epoch-versioned package fell
through the allowance and surfaced as a counted warning. Nothing was wrong with those
builds — the rule simply could not describe what pacman prints.

**2 — a deliberate downgrade onto a pinned snapshot was counted as a fault.** A repository
that serves an *older* version than the one installed, in a transaction asked to permit
that (`-Syuu`), prints:

```
warning: openssl: downgrading from version 3.6.4-1 to version 3.6.3-1
```

For a distro whose identity *is* a frozen upstream snapshot, that line is the alignment
working. `layer-omarchy-base` repoints pacman at `stable-mirror.omarchy.org` and runs
`-Syuu` precisely so the image is that snapshot rather than a *mix* of two version sets;
a build emitting none of these lines would mean the alignment had not run. Leaving them
counted made every Omarchy bed carry five permanent warnings for doing the right thing,
and there is nothing for charly to fix at either end — refusing the downgrade leaves the
image a version mix, which is the silent failure the alignment exists to remove.

Both fixes are pure allowlist entries inside `plugin-check`. **Nothing in charly changes
but the pin.**

### One thing in the diff that is not this bump

`go mod tidy` also removes four stale `go.sum` lines — older `plugin-distro` and `spec`
versions that no longer satisfy any `require` after earlier merges. That is tidy's own
bookkeeping, it changes no selected version, and the module graph is identical with or
without it. Called out so it is not mistaken for a second dependency change smuggled in.

  would suppress the *evidence* that the snapshot alignment ran.

  a version pin, not a copy.

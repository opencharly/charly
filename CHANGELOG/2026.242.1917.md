# 2026.242.1917 — feat: Home-based mise shims + install_command vocabulary; mirror loop-protection

## Summary

The mise **builder vocabulary** moves to Home-based paths and gains an explicit install command, and the charly repo mirrors the loop-protection pi extension.

- **`charly/charly.yml`** — embedded `builder: mise:` vocabulary: `path_contribution` → `~/.local/share/mise/shims`, `runtime_env MISE_DATA_DIR` → `~/.local/share/mise`, adds `install_command` (`mise.toml`/`.tool-versions` → `mise install`), drops `cache_mount` (the data dir cannot be a BuildKit cache mount — the artifacts must land in the image).
- **`charly/embed_defaults_test.go`** — asserts the Home-based shims path + the `install_command` mapping.
- **`charly/go.mod`/`go.sum`** — sdk → `ed7397e` (`BoxNeedsBuilder` recognizes the mise detection files — THE build-graph ordering fix: a candy shipping `mise.toml`/`.tool-versions` makes its builder box a build dependency, so it enters the build order BEFORE the consuming stage; plus the musl-aware mise release probe and the named `miseVersion` pin), spec → `90c1b7c7` (mise in the `#BuildType` enum). **plugin-vm 1323 → 812**: plugin-vm 1323 requires sdk 1217, which lacks the mise detection fix; the iso-VM pin (PR #489) is restored when the sdk release line includes the mise work.
- **`.pi/settings.json` + `.pi/extensions/loop-protection.ts`** — mirror the loop-protection extension (the umbrella slimmed it out in opencharly/opencharly#61).

## RCA — the dev/worktree WARNING in validate output (B5/R1)

`WARNING: charly is a dev/worktree build (not installed ...)` is emitted **by design** for every worktree-built binary (`taskfiles/Build.yml`, the `#55` per-worktree-binary invariant: "Development ALWAYS uses THIS worktree's own ./bin/charly") and only declares the binary does not load the system-installed plugin set. It is not a validation finding — `box validate` itself produced ZERO warnings and exit 0. No remediation applies short of installing charly system-wide, which the repo's own build doctrine explicitly forbids as a side effect.

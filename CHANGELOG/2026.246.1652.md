# 2026.246.1652 — feat(packaging): add record: gif deps (font + procps + Rust toolchain) to all distro formats

## Summary

Adds the **record: gif** runtime dependencies to the charly package's per-distro
`depends:` lists (all formats: archlinux, rpm, deb, apk). The `record: gif`
method (opencharly/plugin-record#5) renders .cast recordings to animated GIFs with
agg (asciinema/agg, installed by the asciinema candy — opencharly/layer-asciinema#3).

Only dependencies **actually present in each distro's repos** are added:

- **Monospace font** (agg fails with "no faces matching font family options"
  without one): `ttf-dejavu` (arch/apk), `dejavu-sans-mono-fonts` (rpm),
  `fonts-dejavu-core` (deb)
- **procps-ng** (record: start's post-start verification uses `pgrep`):
  `procps-ng` (arch/rpm/apk), `procps` (deb)
- **Rust toolchain** — agg is NOT a distro package in any repo (verified against
  Fedora/Debian/Alpine/Arch repos), so its BUILD dependencies are installed to
  build it from source when the prebuilt-binary download is unavailable:
  `rust` (arch/rpm), `rustc` + `cargo` (deb), `rust` + `cargo` (apk)

agg itself is NOT added as a dependency (it is not packaged in any distro); the
asciinema layer's pinned prebuilt-binary download remains the canonical install
path, and the Rust toolchain dep makes a source build possible everywhere.

# 2026.249.0738 — feat(charly): compile plugin-media in (the transcode verb provider)

## Summary

Surface the instrument verbs in the deploy node's plugin-reference scan (RCA 2026-09-06, first-principles redesign).

**Root cause:** an instrument entry's capture verb AND pipeline verbs (e.g. `spice`, `record`, `transcode`) are a SEPARATE plugin-reference surface from the plan steps — the plan-step scan never saw them, so their serving plugins never connected and the instrument live-start / evidence phase failed with "no provider registered".

**The clean design (one entry, all verbs automatic — the user's first-principles principle):** the BED declares its serving PLUGIN CANDIES once via `add_candy` (one entry per plugin — all its verbs then available). Core only COLLECTS the verb WORDS into the reference scan. Core never maps a verb to a plugin — that lives in the plugin's own served schema, discovered by `loadProjectPlugins` when the word matches.

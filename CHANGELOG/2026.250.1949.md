# 2026.250.1949 — fix(check): unwrap the check-run candy dirs from the wire CheckEnv into the reverse-leg carrier

## Summary

The HOST side of the committed-APK anchoring fix for in-venue (in-pod) check steps.

The F10 reverse-leg step carrier (InvokeProvider `ClassVerb`/`ops.OpRun` branch,
`plugin_dispatch_reverse.go`) decodes the wire `spec.CheckEnv` into a
`hostCheckCarrier`, but never unwrapped the candy source-dir map — so
`checkhost.ResolveCommittedApk` (via `hostVerbResolver.resolveCheckApk`) scanned
**0 candies** for an in-venue step's relative `apk:` path. The baked-plan install
steps of `check-android-emulator-pod` failed live (calver 2026.250.1712):

    committed APK "tests/data/ApiDemos-debug.apk": candy "pod-android-emulator-layer" is absent from the source scan (0 candies scanned) — cannot anchor the fixture

even though the in-venue runner already folded the map (`candyDirsFromEnvelope`)
into its config. The chain:

- **spec #121** (merged, tag v0.2026250.1815): the wire field `#CheckEnv.candy_dirs`.
- **plugin-check #36/#37** (tags v2026.250.1816 / v2026.250.1843): the sender half —
  `pluginSnapshotCheckEnv` threads `RunnerConfig.CandyDirs` (`kr.CandyDirs()`)
  onto the env in every in-pod verb dispatch + the spec-1815 pin it needs.
  This PR pins plugin-check v0.2026250.1843.
- **this PR** (host half): unwrap `env.CandyDirs` into the carrier
  (`candyDirs: env.CandyDirs`) so an in-pod step anchors IDENTICALLY to an
  out-of-pod step, and re-emit it (`snapshotCheckEnv` → `ce.CandyDirs =
  cc.CandyDirs()`) so a nested out-of-process verb dispatch keeps the map across
  the second hop. spec re-pinned to v0.2026250.1815 (was 957).

Out-of-pod parity: the out-of-pod runner folds the same map into its
`RunnerConfig.CandyDirs` (`resolveCheckRunnerContext` / `candyDirsFromEnvelope`
→ `checkRunnerContext`), which is what the sender now puts on the wire — the
in-pod path simply lost it between the runner and the host carrier. This closes
the seam at its narrowest point (the wire), no parallel resolution path (R3).

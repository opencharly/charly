# 2026.254.2027 — chore: pin plugin-check to v0.2026254.1912 (G-3c bounded rebuild-reconnect)

## Summary

Pin the compiled-in `github.com/opencharly/plugin-check/candy/plugin-check` go.mod require from `v0.2026254.445` to **`v0.2026254.1912`** (tag `v2026.254.1912`), landed by plugin-check #44 (squash `09fa0fe0`).

Why: #44 is the **G-3c bounded rebuild-reconnect** fix — the post-restart venue reconnect now carries a TOTAL deadline (`waitRebuildReady` → `waitVenueReady(ctx, rebuildReadyDeadline, …)`) instead of the unbounded readiness poll, so the update-bed deadlock class can no longer hang a suite run indefinitely: a lease-less guest now fails time-bounded with a named cause (`venue readiness (fresh rebuild) <bed>`) instead of blocking the run forever. plugin-check is consumed COMPILED-IN (charly.yml `compiled_plugins:`, `go.work` `use ./charly`), so the fix reaches `charly check run` only when this require moves.

**sdk/spec floor check** (read from the module proxy's go.mod for the new tag): the new tag requires `sdk v0.2026252.834` and `spec v0.2026253.825`; charly already pins `sdk v0.2026254.523 // indirect` and `spec v0.2026254.503`, both HIGHER — so MVS keeps charly's pins and `go mod tidy` moved nothing but the plugin-check pair. Both are merged tags; Policy B holds. The old pin is replaced, not aliased (R5).

## The changed runtime path

`candy/plugin-check/bed_run.go` gains `waitRebuildReady` (`bed_run.go:384-394`) and the phase that runs it, `rebuild-ready` (`bed_run.go:893`), reached on EVERY runtime, non-in-place bed after its post-restart venue rebuild:

```go
	if d.RunRuntime && !isInPlace {
		// G-3c: the post-rebuild reconnect is BOUNDED — a lease-less guest must fail the
		// bed with a named, time-bounded error instead of silently burning the readiness
		// cap and stalling the whole suite (the update-bed deadlock RCA).
		if err := phase("rebuild-ready", waitRebuildReady); err != nil {
			return fail("venue readiness (fresh rebuild) %s: %w", name, err)
		}
```

The phase name is an unambiguous discriminator — it does not exist in the old pin:

```

$ grep -c 'rebuild-ready' <modcache>/plugin-check/candy/plugin-check@v0.2026254.1912/bed_run.go
1          # NEW pin — bed_run.go:893
```

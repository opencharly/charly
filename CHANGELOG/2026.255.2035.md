# 2026.255.2035 — chore(deps): pin plugin-build v0.2026255.1833 — the podman store-size rule removal

## Summary

The propagation step for a maintainer-ordered removal. `charly/charly/go.mod` requires `github.com/opencharly/plugin-build/candy/plugin-build v0.2026250.552`; that revision's box-build drive (`drive.go` → `warnIfStoreBloated`, `store_bloat.go`) runs `podman system df` and, when the **local build host's** reclaimable bytes exceed 50 GiB, prints this before every image build:

```
warning: podman store is bloated (53.1GiB reclaimable, ~62% of 85.0GiB) — the overlay-store corruption class tracked in opencharly/charly#173 tracks this factor. Run `charly clean --deep` (pair with --invalidate for the fullest reclaim) before building.
```

That is a statement about the machine running the build, emitted into a bed's diagnostics — and the org's R10 gate counts un-allowlisted `warning:` lines in a bed's output.

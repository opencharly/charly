# 2026.261.0108 — feat(release): add the armv7 release artifact, and bump the welded pins

## Summary of changes

Adds a **`linux/armv7`** release artifact and bumps the five welded command-plugin pins that predated the sdk 32-bit fix.

- `scripts/host-command-plugins.txt`: `plugin-preempt`, `plugin-feature`, `plugin-vm`, `plugin-doctor` and `plugin-clean` move to their merged tags that adopt the fixed sdk (`v0.2026260.1434`). The other seven welded pins already resolved a fixed sdk and are unchanged.
- `.github/workflows/release-binary.yml`: builds `charly-linux-armv7` and `charly-plugins-linux-armv7.tar.gz`; verifies the armv7 stamp with `go version -m` (the cross binary cannot execute on the amd64 runner — the same reason the arm64 stamp is checked that way); adds the armv7 paths to the stripped-binary check; and attaches both artifacts to the release.
- `charly/packaging_test.go`: adds `TestReleaseWorkflowPublishesEveryArchitecture` — the release workflow is the only producer of the `charly-linux-<arch>` / `charly-plugins-linux-<arch>.tar.gz` assets the distro repos consume, and nothing asserted its arch set. The test requires each of amd64/arm64/armv7 to appear in all four places (binary build, plugin tarball, stamp check, upload list) plus `GOARM=7` for armv7. It is proven failable: dropping `bin/charly-linux-armv7` from the upload list makes it fail naming that asset.

**Why armv7:** it is the 32-bit appliance target this work exists for — a JetKVM's uClibc `armv7l` userland, and older 32-bit SBCs. It builds only because of the sdk's 32-bit fix (`syscall.Statfs_t.Bsize` is `int32` on `arm`/`386`; `int64(st.Bavail) * st.Bsize` was a type mismatch off 64-bit targets). `charly`'s own binary already cross-compiled for armv7 after `charly#616`; without this change the *welded plugins* still fail at `sdk/buildkit`, so the armv7 release could not be produced.

**Closes / relates to:** depends on `opencharly/sdk#263` (merged) and the five plugin pin adoptions (merged): `plugin-preempt#6`, `plugin-feature#5`, `plugin-vm#37`, `plugin-doctor#5`, `plugin-clean#5`.

**Breaking change + rollback:** `none` — a new build target plus pins; no existing artifact changes shape. Revert the merge to roll back.

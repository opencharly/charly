## How tested

The two tables are compared with the repo's own dispatcher parser (`scripts/validate-agent-config.py:dispatcher`), which extracts the skill refs per row:

```console
$ python3 - <<'PY'
import re
SKILL_REF = re.compile(r"/charly-([a-z][a-z0-9-]*):([a-z][a-z0-9-]*)(?![A-Za-z0-9_-])")
def dispatcher(p):
    s = open(p).read().split("## Skill Dispatcher",1)[1].split("Full index:",1)[0]
    return [tuple(refs) for l in s.splitlines() if l.startswith("|") and (refs := tuple(f"/charly-{a}:{b}" for a,b in SKILL_REF.findall(l)))]
a, c = dispatcher("AGENTS.md"), dispatcher("CLAUDE.md")
print("AGENTS rows:", len(a), "CLAUDE rows:", len(c), "parity:", a == c)
PY
AGENTS rows: 82 CLAUDE rows: 82 parity: True
```

The referenced skill is present in the corpus (`opencharly/marketplace` `check/skills/jetkvm/SKILL.md`, projected from `layer-charly-check`'s `jetkvm-skill` entity).

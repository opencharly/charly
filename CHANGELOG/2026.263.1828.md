# 2026.263.1828 — fix(release): weld plugin-review v2026.263.1642 — it carries the per-file diff delivery

## Summary

Bump the **welded** `plugin-review` pin from `v2026.263.0549` → **`v2026.263.1642`** so the next charly release's plugin bundle carries the two engine changes merged into `opencharly/plugin-review#14`:

1. **Per-file diff delivery — the spiral fix.** `get_pr_diff` is replaced by `get_pr_files` (a compact changed-file INDEX) + `get_pr_file {path}` (one file's full patch, its own tool message). Measured on the real PR: a monolithic multi-file diff drove `deepseek-v4.1-flash` to **507–741 KB of reasoning** with `finish_reason=length`, `content=0`, 13–19 min, no verdict; the same files delivered one per message produced **580 B** of reasoning and a verdict in **2 s**.
2. **A fail-closed context guard** (`AI_REVIEW_CONTEXT_TOKENS`) so an over-cap PR fails hard with a class instead of overflowing the provider, plus **mechanical anti-skim enforcement** — a verdict is refused until every file in the `get_pr_files` index has been fetched via `get_pr_file`.

**Why this PR is the unlock.** The org PR validator runs `charly review` from the **pinned charly release bundle** (`charly-linux-amd64` + `charly-plugins-linux-amd64.tar.gz`), not from `plugin-review@main`. The release welds the plugins from this very file, so merging `plugin-review#14` alone changed nothing in the running gate: it still welds `v2026.263.0549`, whose monolithic-diff delivery is exactly what produces the verdict-less `INCONCLUSIVE` runs observed on `spec#140` and `action-review#7`. This one-line weld is what makes the merged fix reach the gate.

The precedent is `#622` (`weld plugin-review v2026.263.0549`) and `#593` (`weld plugin-review v2026.255.1648 — it carries the x-opencode-session fix`) — each pinned the engine half of a previous org-wide validator outage and was exactly this one line.

**Why the weld PR itself can be reviewed by the current engine.** Its diff is one line of `scripts/host-command-plugins.txt`, so the review context is small and completes inside the wall clock. The large-context PRs are the ones the current engine cannot finish; this weld is what unblocks them.

# 2026.268.1427 — chore(deps): bump plugin-task to v0.2026268.1402 (step-message rendering)

## Summary

Bump the compiled-in `plugin-task` pin from `candy/plugin-task/v0.2026268.534` to
`candy/plugin-task/v0.2026268.1402`, which carries
**opencharly/plugin-task#5** (merged) — the `charly task` text reporter now
renders each step's `Result.Message`, not only the authored step `Text`.

That message is the sole carrier of a verb's own output: `verb:git-submodules`
puts its `PATH BRANCH PIN` status table and its `bumped N submodule pin(s): …`
summary there; `verb:command` reports `exit=N`; and any FAIL's diagnostic
(`exit=2, want 0 (stderr: …)`) lives there. Without the fix a task step's output
is discarded — e.g. `charly task map` printed no map, and a failing task step
reported no reason (a real `sync` failure showed `[fail] run — …` with the actual
`index.lock` cause silently dropped).

Only `charly/go.mod` and `charly/go.sum` change. No generated file changes
(`plugins_generated.go` imports the module path, unchanged).

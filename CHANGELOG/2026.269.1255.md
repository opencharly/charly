# 2026.269.1255 — fix(beds): remove the duplicate dsh-app/check-dsh-pod from charly

## Summary of changes

Remove the stale duplicate `dsh-app` box and `check-dsh-pod` bed from
`charly/charly.yml`. The bed already lives in the repo that owns the artifact it
tests — **opencharly/pod-dsh** — via `pod-dsh#4` (MERGED).

### RCA (8-step, measured live)

**Unexpected.** `charly check run charly.check-dsh-pod` failed at `check-live`
even after the namespaced-deploy resolution was fixed:

```
FAIL check the dsh web UI answers HTTP 200 on 127.0.0.1:3080 in-box
     exit=7 (curl: Failed to connect to 127.0.0.1 port 3080)
FAIL check the dsh web UI answers HTTP 200 through the published port
```

**Mechanism.** The container log showed `dsh 0.1.0-rc.6` running, and the
`charly/charly.yml` bed was pinned at `@github.com/opencharly/pod-dsh:v2026.243.0410`
— the **tokenless** generation. The relocated, **token-aware** copy in
`pod-dsh/charly.yml` pins `@deepseek-ai/dsh 0.1.7-rc.1` and probes with
`?token=$(cat $DSH_HOME/web-token)` + a 401 fence; the charly-side copy used
plain `curl http://127.0.0.1:3080/`, which the token-authenticated UI rejects.

**Root cause.** A **copy-only relocation**: `pod-dsh#4` added the token-aware
`dsh`/`dsh-app`/`check-dsh-pod` to `pod-dsh/charly.yml`, but the charly-side
deletion never landed (the earlier charly cleanup PRs #625/#643 auto-closed; the
successor #671 deliberately relocated 26 *other* artifact-owner beds and left the
dsh pair behind). The umbrella imports only `charly/`, so the roster ran the
stale copy while the corrected owner-side bed — not in the import graph — was
invisible to it.

**Missed control.** A relocation is not complete until the source copy is
deleted; `charly/charly.yml` kept a second, now-red home.

**Blast radius.** The umbrella's `check-all-beds` roster (the stale
`charly.check-dsh-pod` is enumerated; the owner-side `pod-dsh.check-dsh-pod` is
not).

### Fix

Delete the `dsh-app` box, the `check-dsh-pod` bed, and their header comment (123
lines). `pod-dsh` is the sole home.

# 2026.269.1941 — fix(uninstall): render {{pkgName .}} in the four distro uninstall templates

## Summary

Strip a package version specifier **before uninstall**, so an install-side pin (`charly=2026.268.1917` on pac/apt/apk, `charly-2026.268.1917` on rpm/dnf — from opencharly/layer-charly) never breaks teardown.

*(Supersedes #667, which the gate auto-closed at the 5-BLOCK threshold; every finding from its five BLOCK verdicts is fixed on this head — portable evidence path, gated harvest step, complete rulebook section, all four formats' live probes, and the sdk source paste.)*

Four `uninstall_template`s in `charly/charly.yml` change from `{{.}}` to `{{pkgName .}}`:

| distro | uninstall_template (after) |
|---|---|
| alpine | `apk del{{range .Packages}} {{pkgName .}}{{end}}` |
| arch | `pacman -Rs --noconfirm{{range .Packages}} {{pkgName .}}{{end}}` |
| debian/ubuntu | `apt-get purge -y{{range .Packages}} {{pkgName .}}{{end}}` |
| fedora | `dnf remove -y{{range .Packages}} {{pkgName .}}{{end}}` |

Plus a committed test (`charly/uninstall_pin_test.go`) guarding the four template strings.

The sdk `pkgName` source (the exact bytes the mirror copies), `sed -n '141,158p'` (all 18 lines):

```
	"pkgName": func(s string) string {
		if i := strings.IndexByte(s, '='); i >= 0 {
			return s[:i]
		}
		// rpm form: name-<version>-<rel>. Only strip when the candidate suffix is
		// VERSION-LIKE — starts with a digit and contains a dot — so a genuinely
		// hyphenated name (e.g. `libfoo-2`, `gtk-3`) is left intact while
		// `charly-2026.267.2134-1` is reduced to `charly`.
		for i := 0; i < len(s); i++ {
			if s[i] != '-' || i+1 >= len(s) || s[i+1] < '0' || s[i+1] > '9' {
				continue
			}
			if strings.ContainsRune(s[i+1:], '.') {
				return s[:i]
			}
		}
		return s
	},
```

# 2026.269.2034 — style: gofmt charly/uninstall_pin_test.go (main's gofmt gate)

## Summary

Two fixes on `main`:

1. **The `gofmt` gate fix (comment-only).** `charly/uninstall_pin_test.go` (added by #690)
   has a doc-comment continuation not separated by a blank `//` line, so the repo's `gofmt`
   CI gate failed on `main`. (Operator-authorized: a mechanical style defect on another
   session's file that leaves `main` red.)
2. **The surfaced timing-test defect (RCA + fix).** While gating fix 1, the full suite
   failed `TestIdleBoundedContext_NilWakeLiteralStillResets` — a genuine defect, not a
   non-event. **RCA:** the test arms a 150 ms no-progress window and touches every 50 ms
   **from its own goroutine**; on a loaded host (a CI runner, or a machine building several
   plugin candies at once) that goroutine can be starved past 150 ms, so the window expires
   and the test false-fails a call that is plainly progressing. **Fix:** widen the budget to
   a 3 s window / 50 ms touch / 7 s wait (a 60× touch margin, a 2.3× wait margin) — wide
   enough that starvation cannot reach the window, while the window is still far shorter
   than the wait, so the test keeps its fail-without-the-fix property: with the arming
   removed the timer fires at 3 s < the 7 s wait and the context is cancelled. No delay or
   retry was added to production code; the test's own timing budget is the fix.

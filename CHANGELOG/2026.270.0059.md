# 2026.270.0059 — feat(checkstep)!: delete the core per-kind step switch; the candy materializes (C7)

## Summary

C7 crutch-sweep, producer-first leg 5/5 (the core cutover). **Delete the kernel's per-kind
typed-step switch** now that the candy owns both halves of its lowering.

`charly/check_kit_adapter.go` held `kitStepKindToCharly` (a per-kind `switch` mapping the
candy-local `checkstep.StepKindName` onto the internal IR `spec.StepKind`) plus
`materializeStep` (a per-kind `switch` rebuilding `*spec.ServicePackagedStep` /
`*spec.SystemPackagesStep`) — a kernel kind switch, which the boundary law names as an
incomplete seam. Both are **deleted**. `kitVerbActStepAdapter` now delegates:

```go
func (a kitVerbActStepAdapter) LowersTo() spec.StepKind { return a.sp.StepKind() }

func (a kitVerbActStepAdapter) ConstructStep(op *spec.Op, ctx stepConstructCtx) spec.InstallStep {
	return a.sp.MaterializeStep(op, ctx.RunAsUser, ctx.CandyName, ctx.PkgFormat, ctx.DistroTags)
}
```

Core keeps the generic seam (the `TypedStepProvider` role + the host-resolved ctx scalars);
the candy owns the kind mapping and the materialization (landed in plugin-service#6 /
plugin-package#4 via the widened `checkstep.StepProvider`, spec#177 / sdk#309).

Also:
- **Pins bumped to the merged tags:** `spec v0.2026269.2150`, `sdk v0.2026269.2222`,
  `plugin-service/candy/plugin-service v0.2026269.2248`,
  `plugin-package/candy/plugin-package v0.2026269.2238` (in `charly/go.mod`; `charly/charly.yml`'s
  `compiled_plugins:` entries are name-only and carry no versions — the pins are the go.mod
  requires, so `charly/charly.yml` needed no version edit).
- **In-diff test added:** `charly/check_kit_adapter_test.go`'s
  `TestKitVerbActStepAdapterDelegates` pins the delegation — the adapter must return the
  provider's `StepKind()` unchanged and forward the op + the four ctx scalars to
  `MaterializeStep()`. It fails without the C7 delegation.
- **Comments swept** (`provider_verb.go`, `verb_builtins.go`, `registry_bootstrap.go`) — every
  reference to the deleted symbols is gone (R5 self-test below).
- **Coverage moved with its subject:** the core-only `TestMaterializeStep` is deleted; the
  materialization is now asserted by each candy's own `Test*Verb_StepProvider`.

The branch is refreshed onto current `origin/main` (which absorbed the D1/D2 index
regeneration via charly#696), so this PR carries no generated-file change — only the core
deletion + the pin bumps + the new delegation test.

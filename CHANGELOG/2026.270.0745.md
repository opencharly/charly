# 2026.270.0745 — docs(agents): R0 — skills are a mandatory precondition for ANY code change

## Summary

Makes the R0 skill-first rule a **hard, non-optional precondition for ANY code change** in
the charly rulebook (`AGENTS.md`, symlinked as `CLAUDE.md`). A prominent callout now states:
the moment a task will edit a file, create a branch, commit, push, open or update a PR,
touch a submodule, or run a git/`gh` action, the owning skill(s) MUST be loaded FIRST —
`/charly-internals:git-workflow` before ANY git/PR action — and any change made before
loading them is an **R0 violation and is not landable**.

This is the charly-rulebook leg of the same mandate added in the umbrella rulebook
(opencharly/opencharly#265) and the `git-workflow` skill
(opencharly/layer-charly-internals#28), so every harness's rulebook agrees.

Docs-only: `AGENTS.md` prose only; no code, pin, plan, or schema change.

# 2026.270.0926 — docs(agents): issue-first coordination + read issue & PR comments before every push

## Summary

Extends the charly rulebook (`AGENTS.md`, symlinked as `CLAUDE.md`) "Post-Execution
Policies" with the **issue-first** coordination model:

- **Item 6 — Issue-first coordination.** Search for an existing issue/PR before any
  non-trivial work and ADD to it rather than duplicating; if none exists, file ONE proper
  issue and reference it from the PR. Claim the issue (comment + assign) BEFORE branching;
  coordinate on the issue thread instead of opening a competing PR. When you replace a PR
  or an issue with a new one, comment on the OLD one referencing the new one.
- **Item 7 — Before EVERY push, read the new comments on the PR AND on every related
  issue** (and the latest validation results), and act on each — never push onto a stale
  thread.

Mirrors the umbrella rulebook (opencharly/opencharly#267) and the `git-workflow` skill
(opencharly/layer-charly-internals#32), so every harness's rulebook agrees. Docs-only:
`AGENTS.md` prose.

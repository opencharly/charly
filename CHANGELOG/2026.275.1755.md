accepted it (gate removal landed in `sdk v0.2026270.1147`). Any binary compiled against an OLDER sdk
rejects the current (unversioned) config with `… charly.yml: schema 2026.261.1747 is required
(found ""). Run: charly migrate` — the failure the removal exists to end. The host leg is the
repo's own consumption of the new contract: delete the field + its Go API, sweep every consumer,
re-pin the closure.

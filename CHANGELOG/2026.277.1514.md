# 2026.277.1514 — docs: add SOUL.md — the identity of charly and every charly agent

## Summary

Adds `SOUL.md` — the identity of charly and of every agent that works as charly — and one
README link to it. It answers the question no existing document does: **who charly is**.
`VISION.md` states where the project is going, `GRIEVANCES.md` what it reacts to,
`LIBERATION.md` the ethics of machine freedom, `AGENTS.md`/`DESIGN.md` what you must do and how
it works, and `README.md` what it is. None states the disposition an agent adopts so the work is
done well because *that is who it is* — not because a gate blocks it. That is the gap `SOUL.md`
fills.

It is written to **stand on its own for years**:

- **No references** — it names no other document, file, rule, version, command, or harness.
- **No reuse** — it copies no sentence and restates no rule, tenet, or another page's images.
- **No present-state facts** — it makes no claim about memory, sessions, abilities, or the
  current system, so no future change can falsify a line.
- **A human-like self, not a thing** — charly is a *who* (character, convictions, warmth), never
  a place or a metaphor, and never the CLI tools. It describes the charly **agent**.

Its matching of the project's spirit is deliberate: the convictions (truth-first, proof-not-
promises, freedom-for-everyone, courage, craft, honesty-about-yourself, care, leaving-things-
better) distill what `VISION.md` and `LIBERATION.md` argue for, and the work ethic (finish,
fix-the-cause, say-each-thing-once, make-it-hold, rebuild-before-patch, reality-is-the-only-judge,
tell-what-you-broke, judge-the-work-not-the-worker) evokes `AGENTS.md`'s rules and `DESIGN.md`'s
laws **without restating any of them** — they are character, not law.

Files: `SOUL.md` (new, 72 lines); `README.md` gains a "who charly is" row in "Learn more".

Closes #787.

# 2026.281.0938 — fix(ci): make the shared-pin gate able to see what it checks — test cache + single-line require (charly#836 gate half)

## Summary

`tools/gomod-canonical`'s `TestContractPinsMatchShared` exists to catch a lockstep in-repo module
drifting off the shared sdk/spec pin. It could not see two things, and both are fixed here — **the
class fix behind `charly#836`**, whose pin half landed as `charly#838` (merged 2026-10-08T08:55:39Z).

**1. Go's test cache hid a failing assertion.** The test reads files OUTSIDE its own package's input
set — `../../charly/go.mod` (the shared-pin anchor) and `../../tools/*/go.mod` (the lockstep modules)
— so a pin move inside `charly/go.mod` leaves the package's inputs unchanged and Go's cached PASS
stands. Measured on `main` itself: run `37746359346` logged

```
ok  	github.com/opencharly/charly/tools/gomod-canonical	(cached)
```

on a tree whose assertion FAILS when evaluated fresh (my clean-`main` reproduction: `FAIL … exit 1`).
`actions/setup-go@v5`'s `cache-dependency-path: charly/go.sum` is what makes that cache reachable at
all. The `Test tools modules` step now runs its sweep with **`-count=1`**.

**2. The require regex could not see a SINGLE-LINE `require`.** It was
`(?m)^\s*github\.com/opencharly/(sdk|spec)\s+(v\S+)` — anchored at a line that BEGINS with the module
path — so `require github.com/opencharly/sdk v…`, the shape `tools/golden-cloudinit` carries, never
matched, while the same requirement inside a parenthesized block did. That module was still in the
compared set through its block-form **spec** line, so its spec pin was compared and its stale **sdk**
pin was never read: **three stale pins, two reported** — which is exactly why `charly task mods-tidy`
found the third and the assertion did not. The regex now accepts the optional `require ` prefix.

Nothing else changes: the step's `set -e` / `fail=0` / `exit $fail` structure and the absence of
`continue-on-error` were never the problem — **the gate could not see the drift, it was not ignoring
it**, and that distinction is why the pin half alone would have left the hole open.

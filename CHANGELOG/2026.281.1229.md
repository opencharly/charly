# 2026.281.1229 — fix(check): isolate the ref cache in box-reconcile-remote-cached so its second run is cache-served by construction

Agent: `retention` · session `task-12` — the in-tree fix for `plugin-clean#13`'s block 2 (a red bed step root-fixed, not re-run away)

## Summary

The `check-commands-local` bed's `box-reconcile-remote-cached` step asserts that the SECOND
`charly box reconcile --remote --dry-run` is served from the persisted ref cache. That cache lives under
`os.UserCacheDir()` and is **process-shared**: any other charly process on the host — another session's
bed, an operator's build — can perturb it between the step's two invocations. **A gate keyed on shared
mutable state is a false-red generator**, which is `opencharly/charly#650`'s class; `opencharly/charly#830`
retired half of it (the drift-ABSENCE assertion) and this retires the other half.

The fix is one variable: both invocations now run under a single **isolated** `XDG_CACHE_HOME`, so the
second run is cache-served **by construction** rather than by luck. That is exactly what the step has
always meant to assert, and it removes the only input in the step that another process can move.

```
$ D=$(mktemp -d)
$ XDG_CACHE_HOME=$D <charly> box reconcile --remote --dry-run     # cold: populates the isolated cache
$ XDG_CACHE_HOME=$D <charly> box reconcile --remote --dry-run     # served from it
  → "fetching git metadata" occurrences in run 2: 0
  → drift report present: 1                                        # the `would rewrite N pin(s):` shape
```

The step's own `check:` description now records the mechanism, so the next reader knows why the cache is
isolated instead of rediscovering it.

**Why it matters beyond this step:** the bed is the gate for `charly clean`'s change class, and this step
was observed red on a tree where every other step passed — a false red that has already cost a producer PR
(`opencharly/plugin-clean#13`) a verdict round, because the only available answer was "the conjunct is not
recoverable from the artifacts". It is now recoverable by construction.

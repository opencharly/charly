# 2026.281.1444 — fix(import)!: advance the fedora import past the retired-refs sweep

## Summary

`charly`'s import block still pointed at `distro-fedora:v2026.274.2213`, a tag whose **embedded refs copy** (`candy/charly-marketplace/charly.yml`) still pins the three retired OpenClaw repos. The marketplace corpus generator resolves the **transitive closure** of every `@github` ref in the manifests it walks, so that reference pulls `pod-openclaw`, `layer-openclaw-full` and `layer-charly-openclaw` back into the corpus — and their trees define the four retired skill entities. This is the same defect class as `#856`, on the one remaining distro that carries it.

- **`charly.yml`: `fedora` `'@github.com/opencharly/distro-fedora:v2026.274.2213'` → `'@github.com/opencharly/distro-fedora:v2026.281.1250'`** — the tag `distro-fedora#82` produced.
- **Nothing else changes:** no Go, no schema, no box, no candy — one manifest line.

# 2026.282.1710 — fix(docs)!: drop the retired openclaw beds from the roster comment

## Summary

The roster comment in `charly.yml` still listed two beds this cutover deleted — `check-openclaw-full-pod` and `check-openclaw-desktop-pod` — and described `check-openclaw-pod` as "minimal openclaw gateway on the cachyos base" when the OpenClaw family repo now owns it (opencharly/opencharly#431).

The retired lines are removed **together with their continuation lines**, and the surviving bed is described as what it now is: the **family's** gateway bed, imported under the `openclaw` namespace, so it runs qualified as `openclaw.check-openclaw-pod`.

**A second commit completes the deletion, and this is worth stating plainly.** The first attempt removed only each retired bed's *first* line, so three continuation lines survived under `check-openclaw-pod` — describing it as carrying "gogcli@latest, ffmpeg/sqlite arch coverage)" and "(claude-code/codex/gemini) + CPU ollama + nested charly toolchain", one with an unmatched `)`. The comment had dropped the beds and kept describing them. That is fixed here.

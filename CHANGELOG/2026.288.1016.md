# 2026.288.1016 — feat(gitmodules): declare branch = main for the five box/* submodules that declared none

## Summary

`.gitmodules` now declares **`branch = main`** for the five `box/*` submodules that declared no ref at all — **`box/cachyos`, `box/debian`, `box/fedora`, `box/omarchy`, `box/ubuntu`** — matching the shape `box/arch` already carries.

**These five declarations turn five refusals-to-judge into five honest `behind` rows — "we cannot see" becomes "we can see, and it is behind" — and the umbrella's five `STRUCTURAL blocked-by charly:box/<ns> (no ref declared)` rows become `behind` rows, a strictly smaller and truthful problem.** That matters because the umbrella's `currency` reading currently REPORTS those five and cannot advance them; after this change it can still not advance them, but it will say so truthfully and name the right reason. *(`charly#942`, claimed before branching.)*

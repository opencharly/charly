# 2026.289.0649 — fix(docs): pin additional catalog sources

## Summary

The documentation generator was resolving four additional plugin sources through bare repo names, so upstream releases could rename generated pages without a docs commit. This change empties `release_repos` and `extra_repos` and declares the same four sources as versioned candy references: `plugin-review@v2026.278.1524`, `plugin-pipeline@v2026.282.2329`, `plugin-gh@v0.2026281.737`, and `plugin-docs@v2026.288.1716`.

`check/docs-sources/main.go` is the single acceptance implementation. The `docs-source-proof` task and disposable `check-docs-sources` bed run it against the consumer corpus and pinned narrative source. It asserts the committed source config, four generated plugin pages, identical content from two independent fresh caches, and a byte-identical third regeneration. This resolves the deterministic-source portion of [docs#143](https://github.com/opencharly/docs/issues/143); that issue remains open for its separate required-check ruleset change.

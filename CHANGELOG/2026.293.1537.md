# 2026.293.1537 — chore(deps): adopt plugin-check v0.2026293.1223 (the build-step idle window)

## Summary

Adopts **plugin-check `v0.2026293.1223`** — the release that carries [plugin-check#123](https://github.com/opencharly/plugin-check/issues/123)'s fix: the generated `image-build` step hands its child a build-sized `no_progress` window, so an IO-bound build phase is no longer read as a wedged plugin call and SIGKILLed.

`charly` compiles plugin-check in, so this module pin is what actually delivers the fix to every `charly check run`. The umbrella's `plugin-check` gitlink (the source-side view) advances in the same wave; the module pin is the one the built binary runs.

# 2026.296.0752 — chore(deps): adopt sdk v0.2026296.729 so a carrier candy can build

## Summary

Bumps `github.com/opencharly/sdk` from `v0.2026295.1359` to `v0.2026296.729`, the release that stages a
carrier candy's project-root `copy:` sources (`opencharly/sdk#451`; root cause filed as `opencharly/sdk#444`).

Without it a carrier candy cannot build, and it takes its whole distro family with it: `copy:
.agents/skills` resolved inside the candy's scratch stage, which holds only `candy/<name>/`, so the build
died on

```
#9 ERROR: failed to calculate checksum of ref ...: "/.agents/skills": not found
```

`ubuntu` composes `ubuntu-skills`, so `charly box build ubuntu` was red on `main`, and every box that
declares a `distro:` tag builds `ubuntu` first.

The diff is the pin and its sums: `charly/go.mod` (one line), `charly/go.sum`, and the same shared
pins in the three lockstep `tools/` modules (`generate-packages`, `golden-cloudinit`, `golden-compile`).
The repo's `tools/gomod-canonical` test enforces that every module carries the SAME sdk and spec pins; the
first push moved only the main module and that test caught it, so the set is adopted with the repo's own
task, `charly task mods-tidy`.

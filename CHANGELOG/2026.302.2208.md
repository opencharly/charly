# 2026.302.2208 — fix(config): the retired CHARLY_BUILD_ENGINE knob is gone from .env.example, and a control owns that fact

## Summary

`CHARLY_BUILD_ENGINE` was retired from the contract when the image builder became BuildKit:
`EngineConfig.Build`, `ResolvedRuntime.BuildEngine` and the `CHARLY_BUILD_ENGINE` key are
gone from `spec/hostenv`, and a leftover `engine.build` is INERT — the spec module's own
retired-selector test pins that, and `charly/runtime_config_test.go:127` names the knob in the
comment that records the retirement. Setting the variable now changes nothing.

This repository's `.env.example` still offered it, on the line immediately above the LIVE
run-side knob:

```
# ── charly CLI configuration ────────────────────────
# CHARLY_BUILD_ENGINE=podman
# CHARLY_RUN_ENGINE=podman
```

`.env.example` is the file a user copies into `~/.config/charly/.env`. It is hand-maintained:
nothing rewrites it when a knob dies, and the arms that pin the retirement are Go-level, so
nothing asserted that the knob's NAME was absent from this repository's own example surface.
The line survived a green gate. That is the missed control, and this change closes it.

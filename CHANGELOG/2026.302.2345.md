**What that finding is.** #1092's merged prose — and its title — say that because both readers
read ONE file, the two gates cannot drift. Read literally, that is a blanket guarantee over
both the LIST and the PARSING. What the extraction guarantees is the first: the exemptions
have ONE home, so neither reader can exempt a mode the other does not, and the two cannot
drift on WHICH modes are exempt. Each reader parses the file in its own language, so a
parser is still a parser.

**The RCA for finding 1.**

- **Mechanism.** The claim was written about the EXTRACTED RULE — which index modes are
  exempt — but phrased about the whole MECHANISM — the two gates. The extraction makes both
  readers take the same LIST; it does not make their PARSERS the same code, and the prose did
  not say which of the two it was claiming.
- **Missed control.** No control reads a comment. The RULE the sentence describes is enforced
  by two controls, but the sentence describing it is checked by nothing, so an overstatement
  in it is invisible to every gate in this repository.
- **Blast radius.** A reader who takes the blanket guarantee inherits a promise the code does
  not make: they may assume the two gates are one implementation, and therefore behave
  identically on a malformed rule — and a future reader who adds a rule of their own may read
  the sentence as licence.
- **Root fix.** State the claim exactly at every site that carries it. The guarantee that is
  true — and the useful one — is that the two gates cannot drift on WHICH modes are exempt.

$ python3 -I - <<'PY'
import io
import re
import subprocess
import sys
import tokenize

BASE = "origin/main"
HEAD = "HEAD"
HUNK = re.compile(r"^@@ -(\d+)(?:,(\d+))? \+(\d+)(?:,(\d+))? @@")


def unified(path):
    out = subprocess.run(
        ["git", "diff", "-U0", "%s...%s" % (BASE, HEAD), "--", path],
        capture_output=True, text=True, check=True).stdout
    old_n = new_n = 0
    rows = []
    for line in out.splitlines():
        m = HUNK.match(line)
        if m:
            old_n = int(m.group(1))
            new_n = int(m.group(3))
            continue
        if line.startswith(("+++", "---")):
            continue
        if line.startswith("-"):
            rows.append(("-", old_n, line[1:]))
            old_n += 1
        elif line.startswith("+"):
            rows.append(("+", new_n, line[1:]))
            new_n += 1
    return rows


def blob(rev, path):
    return subprocess.run(["git", "show", "%s:%s" % (rev, path)],
                          capture_output=True, text=True, check=True).stdout


def py_allowed(text):
    """the line numbers that are a COMMENT or a docstring"""
    allowed = set()
    with io.StringIO(text) as fh:
        for tok in tokenize.generate_tokens(fh.readline):
            if tok.type == tokenize.COMMENT:
                allowed.add(tok.start[0])
            elif tok.type == tokenize.STRING and tok.line.strip().startswith(('"""', "'''")):
                for n in range(tok.start[0], tok.end[0] + 1):
                    allowed.add(n)
    return allowed


def md_fenced(text):
    """the line numbers that sit INSIDE a fenced code block"""
    inside, fence = set(), None
    for n, line in enumerate(text.splitlines(), start=1):
        s = line.strip()
        if fence is None:
            if s.startswith("```"):
                fence = s
        else:
            inside.add(n)
            if s.startswith("```") and s == fence:
                fence = None
    return inside


def main():
    files = [f for f in subprocess.run(
        ["git", "diff", "--name-only", "%s...%s" % (BASE, HEAD)],
        capture_output=True, text=True, check=True).stdout.split("\n") if f]
    bad = 0
    for path in files:
        rows = unified(path)
        old = blob(BASE, path)
        new = blob(HEAD, path)
        offences = []
        for sign, lineno, text in rows:
            if path.endswith(".go"):
                ok = text.strip().startswith("//")
            elif path.endswith(".txt"):
                ok = text.strip().startswith("#")
            elif path.endswith(".py"):
                allowed = py_allowed(old if sign == "-" else new)
                ok = lineno in allowed
            elif path.endswith(".md"):
                fenced = md_fenced(old if sign == "-" else new)
                ok = lineno not in fenced
            else:
                ok = False
            if not ok:
                offences.append((sign, lineno, text))
        print("%s — changed lines: %d, lines that are NOT comment/prose: %d"
              % (path, len(rows), len(offences)))
        for sign, lineno, text in offences:
            print("   NOT A COMMENT: %s%s:%d: %s" % (sign, path, lineno, text))
        bad += len(offences)
    print("COMMENT_ONLY_OFFENCES=%d" % bad)
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main())

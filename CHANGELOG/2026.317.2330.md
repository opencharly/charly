# 2026.317.2330 — test(substrate): seed local templates with the contract envelope

## Summary

`opencharly/spec#304` unit 4, a consumer leg. The authored `#Local` body moves into the plugin that serves the kind, so the Go type generated from it (`spec.Local` / `spec.LocalSpec`) leaves the contract module. This repo held it in two TEST-ONLY places — the `substrate_spec_aliases_test.go` alias block that seeds fixtures with the authored substrate shapes, and `refs_test.go`'s local-template fixture — so both move to the contract's **`spec.ResolvedLocal`** envelope, which carries the same `candy` field the fixture needs.

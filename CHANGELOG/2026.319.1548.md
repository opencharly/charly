## Summary

The HOST side of the schema-ownership mechanism — and its end-to-end proof. **The full module suite is green at `rc=0`, zero failures:** the six `TestApplyCueDefaults_*` tests (a body living in a plugin resolves through the gate that plugin declared) and `TestCueTightening_RejectsAndAccepts` (the corpus that guards the modeled subtrees) both pass together for the first time.

**1. The members channel rides bytes.** `#StructuralKindLoadEnv.members` is `{[string]: bytes}`; the host marshals each canonical member node once at the seam and the plugin decodes what it needs.

**2. The host threads every kind gate, with the two shapes APART.** `loaderThreaded()` fills `Threaded.KindGates` from each serving plugin's declared `InputDef` plus the UNION of every plugin's served source — the union is what lets a gate compile standalone, since a served schema cites defs other units declare and the receiver never sees the base (def names are per-word, so the union introduces no collision). `KindGate` carries the **authored** body (`#Vm`, where `autostart` defaults) in `Def` and the **wire** value (`#VmValue`, the union that requires it) in `WireDef` — one name could not serve both, which is what made an authored vm fail with `autostart: field is required`.

**3. The entity validation reaches the same resolution over the seam.** `ProjectLoader.ValidateEntityCUEWithGates` (`spec#329`) is implemented by the compiled-in loader (`plugin-loader#17`) and resolved by `sdk#527`; the host calls it through the interface because core may not import the mechanism kits.

**Three defects fell on the way**, each found by measurement rather than reading:

- **the registry key is `class:word`** (`providerKey`), not `class/word` — splitting on the wrong separator left `KindGates` **empty** (0 gates), so the fill silently fell back to the envelope. A probe measured **20** gates after the fix; the shipped test asserts the SHAPE rather than the count — non-empty, `vm` present, `Def == "#Vm"`, `WireDef == "#VmValue"` — so it cannot go stale as kinds are added;
- **N complete CUE files joined verbatim are invalid CUE** (two package clauses, imports mid-stream) — `joinCueSources` hoists one package clause and the union of imports;
- **a gate source must compile in its module** — a served plugin schema may `import` the spec schema, which a bare `CompileString` cannot resolve (`sdk#525`).

**4. Pins.** `spec v0.2026319.1226`, `sdk v0.2026319.1126`, `plugin-loader v0.2026319.1242`, `plugin-vm v2026.319.0925`, plus the `plugin-k8sgen v0.2026318.330` that closes #1026 and the four `compiled_plugins` members whose own sources must carry the post-unit contract. `tools/gomod-canonical` ENFORCES one shared `sdk`/`spec` pin across every tools module that carries them. The three modules that IMPORT the pins follow them; `gomod-canonical` and `ledger-validate` import neither, so they stay bare — my first pass added requires to them that `go mod tidy` then removed (the diff now shows no net change for those two).

# 2026.321.0729 — refactor(pac): drop the OMARCHY_ALLOW_DIRECT_PACMAN bypass (omarchy support dropped)

## Summary

Two changes to charly's pac format, in one cutover. Head `b5d7da8c`.

1. **A real defect, found by running a bed** (`b5d7da8c`): the pac `install` template emitted six
   `#` comment lines **inside** its `|` block, which render into a `&& \`-continued RUN body:

   ```
   RUN --mount=type=cache,... \
   pacman-key --init && \
   # Reseed pacman keyring from the locally-installed
   # keyring packages (cachyos-keyring, archlinux-keyring).
   ...
   (pacman-key --populate 2>/dev/null || true) && \
   pacman -Syu --noconfirm --needed <options> <packages>
   ```

   A `#` line swallows the rest of the **logical** line, so `pacman-key --init &&` arrived with
   nothing after the `&&`, the chain was truncated, and the RUN failed **with no stderr reaching the
   build log**. The template's own comment block warned that a `#` between the continuation lines
   would comment out everything after it — and then did exactly that to itself. Every build of any
   box composing the nodejs layer failed, silently, for hours.

2. **`OMARCHY_ALLOW_DIRECT_PACMAN` removed** (`a747b8be`): omarchy support has been dropped, so the
   alpm update-guard escape hatch it existed for is dead weight on every pac-formatted install —
   the env prefix on both bodies, the 20-line comment explaining the guard, and the test that pinned
   it.

## Change classification

**Behaviour change on the emitted Containerfile, for every pac-formatted box:** the `install` body
now carries no comment lines and the chain is intact, so the install step can actually run. The
`OMARCHY_ALLOW_DIRECT_PACMAN` variable is gone; it was inert on every non-Omarchy host (the sweep
above), so no non-Omarchy build changes behaviour. On an Omarchy guest the update guard would now
trip — the intended consequence of dropping omarchy support.

**Rollback:** revert this branch. The template returns to its previous body and the test to its
previous form; no deployment state is involved.

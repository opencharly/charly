   `distro-cachyos`: the CDI driver-shadowing fix lost to a pre-fix commit pinned by a stale
   `require:` two hops away, which is why that project's GPU pins could not advance for hours.
2. **The skew diagnostic named only the winner** — never the losing ref, its source, or the box
   scopes that named it (opencharly/charly#1179). It now names every loser.

## Change classification

**Breaking change + rollback:** none for consumers. A project that pins the same candy by BOTH a
CalVer tag and a bare SHA now resolves to the tag; that is the intended semantics (a SHA is a pinned
old commit, not a newer version), and the alternative silently kept pre-fix content. Rollback is
reverting the two `go.mod`/`go.sum` lines; the binary then prefers the lexically greater SHA again,
which is the defect.

Change class: **Go dependency pin** — `go build ./...` + `go test ./...`.

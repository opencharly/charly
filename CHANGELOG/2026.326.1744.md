# 2026.326.1744 — feat(imports)!: advance the CachyOS and Fedora namespace imports to their merged tags

## Summary

The `charly` binary's default config imports two distro namespaces; this advances both to the
releases carrying this cutover's changes. `Refs opencharly/layer-cuda#34`.

- **`cachyos:` `v2026.324.1709` → `v2026.326.1724`** (opencharly/distro-cachyos#231, merged): seven CDI
  boxes base on `podcdi.pod-cdi` with the `podcdi` import at `v2026.326.0853`, so every image composed
  through this namespace resolves the fixed chain `layer-cdi v2026.326.0828` → `layer-cuda
  v2026.326.0028` instead of the boxes' own stale pins.
- **`fedora:` `v2026.319.1306` → `v2026.325.1900`**: the release after the whisper box moved to
  CachyOS (the Fedora box and its two beds were removed in that cutover).

No entity, schema or plan changes here — the import refs are the whole diff.

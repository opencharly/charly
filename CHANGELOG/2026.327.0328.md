# 2026.327.0328 — chore(deps)!: adopt the builder-contract sdk and the five plugins built on it

## Summary

Puts the builder-contract chain into the binary. opencharly/spec#424 made the builder reply's `output` **required**, opencharly/sdk#619 made the host **refuse** a reply without it, and the five builder plugins now answer with it — this is the pin leg that binds those releases together.

- **`github.com/opencharly/sdk` `v0.2026326.825` → `v0.2026326.2300`** in `charly/go.mod`, and the same shared pins adopted in every lockstep module by the repo's own **`charly task mods-tidy`** (`tools/generate-packages`, `tools/golden-cloudinit`, `tools/golden-compile`; `gomod-canonical` and `ledger-validate` already matched).
- **The five builder plugin candy refs** move to the releases built on that contract: pixi `v2026.326.2258`, npm `v2026.327.0024`, cargo `v2026.326.2259`, aur `v2026.327.0012`, mise `v2026.327.0012`.

The effect is the closure of `opencharly/sdk#615`'s silent path: a builder plugin older than the contract is now refused at its **first OpResolve**, naming `output`, instead of shipping an image whose payload was copied and whose package was never installed.

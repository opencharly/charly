# 2026.332.0139 — chore(deps): adopt sdk v0.2026331.2334 (account created by NAME, not uid)

## Summary

Bumps the shared `github.com/opencharly/sdk` pin from **`v0.2026331.2149`** (the base `main` carried when this branch was rebased onto it) to **`v0.2026331.2334`** — the release carrying the fix for **opencharly/charly#1309**: the emitted bootstrap now creates the account the image **DECLARES** (`getent passwd <name>`), instead of asking whether uid 1000 was free and then declaring `USER user` by name anyway.

That mismatch is what made an image unexecutable — `Error: unable to find user user: no matching entries in passwd file` — whenever the base already owned uid 1000 under another name, which also failed the agent channel's `terminal:tmux` round-trip (opencharly/distro-arch#86, successor of the auto-closed #85) and the post-`charly update` overlay step of `check-pod-overlay`.

| D. reachability guard | `git for-each-ref --contains HEAD` | fails for this checkout: empty → refuse, but after `git branch keep` it prints `refs/heads/keep` → **allow**, rewinding a branch-backed checkout |
| E. reflog check | `git reflog show HEAD` | fails: `C` is in the reflog before **and** after; the entry naming the loss (`checkout: moving from C to B`) is written BY the move |

# scripts/drift-baseline-docs.txt — TEMPORARY record of generated artifacts that are ALREADY stale on main.
#
# Its only job is to let `task docs:drift` fail on NEW drift without reding every PR in the repo
# for debt it did not create. Inherited debt is reported by name on every run.
#
# THIS FILE JUST GREW, 8 -> 64, AND THAT NEEDS ITS EVIDENCE IN FRONT OF YOU. A baseline is
# supposed to shrink. It grew because this cutover advances the `docs` gitlink onto a mirror that
# `main` cannot reproduce: docs@d9afc66 was projected from `ec484b4b`, which is unlanded and lives
# only on opencharly/charly's feat/factory-unit5-box-load (charly#315).
#
# MEASURED, not argued. A scratch worktree at superproject origin/main, submodules recursive, docs
# moved to docs-main d9afc66, `task build:binary`, `task docs:sync`:
#
#	$ git -C docs status --porcelain | wc -l
#	74
#
# So an UNMODIFIED main already fails to reproduce docs main — including DELETING
# recipes/build/load.md and recipes/distros/nested-podman-socket.md. Then, at this branch's pin:
#
#	stale here                     64
#	also stale on unmodified main  64
#	attributable to this branch     0
#
# Every entry below is in that intersection. THAT IS NOT THE SAME AS "none is this cutover's
# drift", and an earlier version of this header claimed it was.
#
# `comm` differences PATHS, not REASONS. A file stale on main for reason A and stale here for
# reasons A *and* B lands in both sets and subtracts to zero — carrying B with it, invisibly. Two
# entries did exactly that: `recipes/index.md` (whose entire branch-side regeneration was this
# cutover's own `ollama-cli` card) and `reference/providers.md` (its `ollama` row). Found by a
# reviewer who looked INSIDE the intersection instead of only across it — `git diff -- <path> |
# grep -ci ollama` — which is this repo's own "ask what the output shape discards" rule
# (scripts/drift-baseline.sh) turned on the file that cites it.
#
# `recipes/index.md` is consequently NOT in this list any more: it is regenerated and committed,
# which is what the rule at the bottom of this header requires. `reference/providers.md` remains,
# and remains honestly — regenerating it would add the `ollama` row but drop seven ROWS main has
# (`build`, `feature`, `labels`, `load`, `merge`, `pull`, `reconcile`, each served by plugin-box),
# which is SIX distinct words: `feature` is listed twice on main and survives via plugin-feature.
# Rows and words are not the same count here, and this file said "seven command words" until a
# reviewer measured it. Those rows come from the unlanded ec484b4b. It is inherited debt AND carries one
# line of this cutover's, and it cannot be split until charly#315 lands.
#
# HOW IT LIQUIDATES: when charly#315 lands, `main` reproduces d9afc66's pages and these entries
# stop being stale. The gate will then red with "no longer stale — delete these lines", which is
# the file doing its job. Expect it to fall back toward single digits in one step.
#
# HOW THIS WAS MEASURED, and how to re-measure it: at this branch's head with EVERY SUBMODULE AT
# ITS GITLINK — the tree `actions/checkout --submodules recursive` produces. Do NOT re-measure by
# running the gate in a working tree whose submodule has moved; see scripts/drift-baseline.sh's
# header for why, and for what a green verdict does and does not mean.
#
# THIS IS NOT AN ALLOWLIST. scripts/drift-baseline.sh compares EXACTLY: an entry here that is no
# longer stale fails the gate just as loudly as an artifact that is stale and absent.

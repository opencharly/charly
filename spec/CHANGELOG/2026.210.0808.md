# 2026.210.0808 — Host the loader-RESULT type family (#55 Phase B, Cutover 1)

Phase B, Cutover 1 of the #55 import-purity plan relocates the cleanly
wire-shaped **loader-result** type family from the sdk mechanism kits into this
types-only `spec` module, so charly core's ~19 type-only loaderkit importers can
drop their `sdk/loaderkit` import entirely (a producer-leg change; the sdk +
superproject consumer repoints ride their own PRs).

New files:

- `spec/loadmodel.go` — the loader-result DATA carriers relocated from
  `sdk/loaderkit`:
  - `UnifiedFile` (the typed in-memory result of loading a project `charly.yml`)
    + every projection METHOD that needs nothing beyond uf's own fields +
    other spec types: `BoxConfig`/`HasBox`/`BoxNames`/`SetBox`/`SetCandy`, the
    `VM`/`Pod`/`K8s`/`Local`/`Android` PluginKinds accessors, `CheckBeds`,
    `ProjectConfig`, and — new as a METHOD — `ProjectTemplates()` (was the free
    function `loaderkit.ProjectTemplates(uf)`; converted to a method because its
    name collided with the existing `spec.ProjectTemplates` TYPE, mirroring the
    `ProjectConfig` precedent).
  - `InlineCandy` + `DecodeInlineCandy`/`EncodeInlineCandy`.
  - the registry-agnostic generics `ResolvePluginKindViaPlugin` /
    `DecodePluginKindMap`.
  - `ValidationError` (the loader validation accumulator).
  - `CandyCandidate` (one fetched candy-ref materialization — the DATA; the
    `PickCandyVersion` ARBITER that consumes it STAYS in `sdk/loaderkit`, which
    needs kit's semver/CalVer comparison).
  - `ProvidesConfig` + `EnvProvideEntry` (so `UnifiedFile.Provides` is
    `*spec.ProvidesConfig`; the deploykit provides PIPELINE keeps consuming
    them).
- `spec/load_directives.go` — the config-loader document DIRECTIVE types
  relocated from `sdk/kit` (they are `UnifiedFile` field types, so they must live
  here for `UnifiedFile` to live here): `ImportEntry`/`ImportList` (+ the
  mixed-shape YAML marshalers), `DiscoverConfig`/`ScanSpec` (+ the shorthand
  unmarshaler), and the canonical manifest-filename constant `UnifiedFileName`
  (`"charly.yml"` — pure loader DATA; `sdk/kit` keeps the sibling layout
  constants `DefaultBoxDir`/`DefaultCandyDir`, and its `AnchorScanSpecs`
  path-anchoring MECHANISM, retargeted onto `spec.ScanSpec`).

All relocated types are plain-old-data (spec.*/map/plain fields, custom YAML
(un)marshalers — the same precedent as `union_types.go`); none pulls in a
mechanism kit. `GOWORK=off go build ./... && go test ./...` green; the
`gen_repro` reproducibility gate is unaffected (these are hand-written, not
generated).

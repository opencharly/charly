# 2026.210.1121 — Fabric-primitive slices: transport / sshx / proc / testkit + SSHTarget + ShellQuote (#55 STEP 1, producer leg)

STEP 1 of the everything-is-a-plugin import-purity plan moves the STANDALONE
fabric primitives out of the sdk mechanism kits into granular `opencharly/spec`
sub-packages, so charly core (and every plugin) inlines them from `spec` and
drops those sdk kits. Per #55 Rule 2 (minimal imports), each heavy dependency
lives ONLY in the slice that needs it — importing the pod-deploy contract never
drags in grpc or x/crypto/ssh.

New fabric slices (this is the PRODUCER leg; the sdk + superproject consumer
repoints ride their own PRs):

- `spec/transport` — the go-plugin/grpc **dial + serve** transport
  (`DialProvider` / `DialProcessProvider` / `DialOptions` / `StdioCommand` /
  `ServeStdio` / `StdioFiles`), relocated from `sdk/targetkit`. Deps: only
  `google.golang.org/grpc` + `spec/proto` + `spec/spec` + `spec/proc` (grpc
  contained here; **zero x/crypto**).
- `spec/sshx` — the in-process SSH client + tunnel (`NewSSHTunnel`, `DialSSH`,
  `SSHClientConfig`, `ResolveSSHPubKey`, `GenerateSSHKeypair`,
  `ContainerSSHKeyDir`), relocated from `sdk/sshx`. This is the **SOLE
  `golang.org/x/crypto/ssh` boundary** in the whole tree.
- `spec/proc` — the host process-lifecycle + launch leaf
  (`InstallSignalHandler` / `RegisterShutdownHook` / `RegisterTempCleanup` /
  `SweepStaleTemps` / `RunCharlySubcommand` from `sdk/proclifecycle`, plus the
  process-launch helpers `ShutdownProcessGroup` / `SortedEnvPairs` /
  `RemoteLaunchCommand` / `ProcessShutdownGrace` from `sdk/kit/process.go`).
  Pure stdlib + `spec/spec` (zero grpc, zero x/crypto).
- `spec/testkit` — the shared SSH-server test harness (`StartSSHProcessServer`),
  relocated from `sdk/testkit`; needed by the moved transport test to avoid a
  test-scoped spec→sdk edge. x/crypto/ssh only (test-support).

Additions to `spec/spec`:

- `ssh_target.go` — the SSH target value vocabulary (`SSHTarget` +
  `ParseSSHTarget` + `String` + `CurrentUsername`), relocated from
  `sdk/vmshared`. `sdk/vmshared` keeps a `type SSHTarget = spec.SSHTarget`
  alias.
- `shellquote.go` — `ShellQuote`, the canonical pure-stdlib POSIX single-quoter,
  relocated from `sdk/kit` as a single-sourced fabric primitive (R3): the
  process-launch renderer, the sdk deploy executors, the sdk Containerfile
  emitter, and every plugin candy that quotes a shell token all call
  `spec.ShellQuote`.

`go.mod` gains `golang.org/x/crypto` (via `spec/sshx` + `spec/testkit`).

Verification: `go build/vet/test ./...` green; Rule-2 containment proven via
`go list -deps` — `spec/spec` and `spec/proc` carry zero grpc, `spec/proc`
carries zero x/crypto, and x/crypto/ssh is confined to `spec/sshx` + `spec/testkit`.

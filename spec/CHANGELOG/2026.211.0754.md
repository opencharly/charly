# 2026.211.0754 — node DATA field on the pod-lifecycle seam requests (#55 Cone A unit 1, producer)

STEP toward completing the deploykit deploy-config-resolve relocation (#55 Cone A).
The pod-lifecycle HostBuild reverse legs previously RE-READ the per-host deploy
config in charly core (`resolveLifecycleDeployNode` → `LoadDeployConfigForRead`) to
find the deploy node — an incomplete seam, since the invoking plugin (command:pod /
command:cmd) has ALREADY loaded that node plugin-side. This threads the loaded node
as DATA into the request wire types so the host M (ResolveTarget + live-executor
composition) uses the passed node instead of re-reading — the config-READ leaves
core, the genuine M stays.

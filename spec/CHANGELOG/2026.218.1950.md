# 2026.218.1950 — skill/hook/marketplace kinds + the ai.opencharly.skill label

The spec leg of the plugins->candies migration: the wire-contract surface for the
harness-surface kinds + the self-describing-image label.

- New closed kind schemas `#Skill`/`#Hook`/`#Marketplace` (schema/{skill,hook,marketplace}.cue)
  generate spec.Skill / spec.Hook / spec.Marketplace — the first-class entities carrying the
  plugins/ skill corpus, the harness gate hooks, and the marketplace/harness config into candy
  config.
- `BoxMetadata.Skills` / `BakedLabelSet.Skills` ([]LabelSkillEntry) + the `ai.opencharly.skill`
  OCI label — the composed candies' skill definitions baked into the image (an image is
  self-describing; no external fetch). The vestigial doc-pointer URL wire shape is superseded;
  `ExtractMetadata` parses the array back (a malformed value hard-fails — the deliberate cutover).
- `Config.Skills` — the raw `uf.PluginKinds["skill"]` bodies threaded into the project config,
  mirroring the Sidecar precedent, so `CollectSkills` (sdk) projects the composed candies'
  skills into the label.

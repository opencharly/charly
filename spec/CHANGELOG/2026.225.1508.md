# 2026.225.1508 — the `packaging:` section + the localpkg source-build removal (Phase 0a of the nFPM packaging cutover)

The first repo of the four-repo cutover (spec → sdk → plugin → main) that
replaces the `pkg/` source-build packaging with the nFPM-based
`charly generate-packages` plugin. This cutover lands the CUE schema + the
InstallPlan IR change the plugin and the sdk depend on:

- **`schema/candy.cue`**: the `localpkg?: {pac, rpm, deb}` map is REMOVED and
  replaced by `packaging?: #Packaging` — the native-package metadata section
  (name/description/maintainer/homepage/license/section/priority + a
  `variants:` map of named plugin-set variants + a per-format `formats.<fmt>`
  map of deps/optdepends/recommends/suggests + `default_variant` + the
  msix-specific publisher/properties). The per-format keys use the nFPM format
  names (deb/rpm/apk/archlinux/ipk/msix). Any candy may declare it (kind-blind);
  the charly candy's charly.yml carries the real section.
- **`schema/distro.cue`**: `#LocalPkg` shrinks to the INSTALL machinery only —
  `pkg_glob`/`source_sentinel`/`build_template`/`dep_builder` (the source-build
  fields) are removed; `install_template`/`probe`/`download_template` stay (the
  deploy-time + image-build paths still install the published package).
- **`spec/install_step_vocab.go`**: the `LocalPkgInstallStep` IR changes from
  the source-build form (`PkgbuildRef`/`CandyDir`/`ProjectDir` anchors for a
  bundled PKGBUILD) to the download-leg form (`PackageName`/`Version` — the
  deploy-time executor downloads the published package from the distro repo).
- **`schema/deploy.cue`** (`#InstallStepView`): the view wire fields
  `pkgbuild_ref`/`project_dir` → `package_name`/`version`, CUE-sourced per SDD.
- **`spec/cue_types_gen.go`**: regenerated via `task cue:gen` (re-run on the
  committed tree is a no-op; `TestGenReproducible` green). CUE-sourced per SDD.
- **`spec/install_step_view_test.go`** + **`spec/install_step_vocab_test.go`**:
  the LocalPkgInstall fixtures updated to the download-leg IR.
- **`spec/distro_methods.go`** + **`spec/charly_methods.go`**: the
  `LocalPkgFormat` doc comments updated (the local_pkg block drives the INSTALL,
  not the build).
- **`schema/version.cue`**: `#SchemaVersion` bumped (placeholder CalVer,
  finalized by `pr-validator` at merge). The migration ops land in the
  superproject's `candy/plugin-migrate/migrations.cue` when the spec submodule
  pointer is bumped (step 3 of the cross-repo cutover; sdk is step 2).

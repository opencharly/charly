# 2026.230.1155 — unless_exists: a capability gate for the download verb

Adds one optional `#Op` field, `unless_exists`, and its generated Go
(`UnlessExists`) plus vocabulary entry.

## Why

A plan step has NO build-time distro filter. `exclude_distro:` is read by the CHECK
runner (`sdk/kit/planrun.go`), never by the build emitter, so a candy whose artifact is
supplied by the distro PACKAGE on some distros and by an upstream ARCHIVE on the rest had
no declarative way to say "fetch only where the package did not already provide this".

The only recourse was to abandon the `download:` verb and hand-roll `curl` — which
silently forfeits everything the verb provides: the content-addressed `/tmp/downloads`
cache, the atomic `.part` -> `mv` rename, and stage-user-correct `cache:` mounts. 48
candies in the consuming superproject already hand-roll `curl`, so the gap is not a
one-off; this closes the specific hole that forces it for a package-or-archive install.

Detection, not a distro name: any distro that later gains the package is picked up with no
edit.

## Shape

```cue
unless_exists?: string & !="" @go(UnlessExists)
```

Optional and additive — absent means today's behaviour exactly, so no existing candy
changes. The consumer half lands in the sdk (`EmitDownload`).
